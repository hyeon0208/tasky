# Tasky

> 바탕화면에 사는 작은 비서. 내 작업과 AI 에이전트의 상태를 한눈에 보여 주고, 화면 위의 자잘한 일을 대신 정리해 줍니다.

Tasky는 macOS 바탕화면에 늘 떠 있는 펫 앱입니다. 펫을 누르면 원형 메뉴가 열리고, 폴더 열기·파일 변환·키보드 설정·잠깐 쉬기 같은 일을 펫 하나에서 할 수 있습니다. Claude Code·Codex 같은 AI 코딩 에이전트가 일을 끝내거나 내 승인을 기다리면 펫이 알려 줍니다.

> 이전 이름은 **콩깍지(Kongpod)** 입니다. 콩깍지 때 쓰던 설정·캐릭터 그림·로그인 항목·Claude Code/Codex 연결은 Tasky를 처음 실행할 때 자동으로 옮겨집니다(옛 설정은 지우지 않음).

- 플랫폼: macOS 14 (Sonoma) 이상
- 언어: Swift (AppKit, SwiftUI 미사용), Swift Package
- 빌드: Xcode 없이 Command Line Tools만으로 빌드
- 라이선스: [MIT](LICENSE)

## 빠른 시작

```bash
git clone https://github.com/hyeon0208/tasky.git
cd tasky
swift build
.build/debug/Tasky            # 실행
```

- 끄기: 메뉴 막대의 잎 아이콘 → 종료
- 처음 실행하면 펫이 화면 가운데에 나타납니다. 끌어서 원하는 곳에 두세요.
- Command Line Tools가 없다면 `xcode-select --install`로 설치합니다.

### 실행 옵션

| 명령 | 하는 일 |
|---|---|
| `.build/debug/Tasky` | 펫 실행 |
| `.build/debug/Tasky --debug` | 개발자 옵션과 함께 실행 (설정에 '개발자' 탭) |
| `.build/debug/Tasky --selftest` | 자체 검사 (위치 계산·작업 알림·키보드 판정 등) |
| `.build/debug/Tasky --convert <작업> <파일...>` | 화면 없이 파일 변환만 실행 |
| `.build/debug/Tasky --connect claude\|codex` | Claude Code·Codex 알림 연결 |
| `.build/debug/Tasky --disconnect claude\|codex` | 연결 해제 |

## 기능

### 펫과 원형 메뉴
- 포커스를 빼앗지 않는 투명한 펫 창으로, 모든 데스크톱(Space)에 보입니다.
- **끌어서 옮기기**: 빠르게 던지면 미끄러지다 멈춥니다. 위치와 모니터를 기억합니다.
- **빼꼼 아일랜드**: 화면 왼쪽·오른쪽·위·아래 가장자리(구석 포함)에 두면 작은 알약이 되어 붙습니다(라이트·다크 자동). 커서를 올리면 '미니 오늘'(시계·남은 할 일·다음 일정)이 위 알약은 아래로, 옆 알약은 서랍처럼 옆으로 펼쳐집니다. 허락을 기다리는 작업이 오면 테두리 색이 바뀌고 3초간 펼쳐집니다. 끌어내면 보통 펫으로 돌아옵니다.
- **누르기·올리기**(F26): 한 번 누르면 오늘 카드, 두 번 누르면 빠른 실행이 열립니다.
- **오늘 카드**(F27): 할 일·일정·AI 작업 세 덩어리. 일정은 설정한 기간(1~7일, 기본 7일)까지, 맨 아래 '할 일 또는 일정 추가' 칸에 바로 적습니다.
- **일정·할 일 알림**(F27): 일정은 1시간 전(알림에서 5분·10분·30분·1시간 칩이나 굴리는 고르기로 다시 알릴 시간을 고름)과, 알림을 끄지 않았다면 시작할 때, 남은 할 일은 정한 간격마다(기본 60분, 끌 수 있음) 곰 옆에 '지금 하나에 집중' 패널로 한 번에 하나씩 알립니다. macOS 집중 모드가 켜져 있으면 띄우지 않습니다(앱으로 실행했을 때 집중 상태 권한을 한 번 묻습니다).
- **빠른 실행**: 화면 가운데 명령 바. 일정으로 읽히는 입력이면 어느 캘린더에 언제 저장될지 미리 보여 줍니다.
- **할 일 창**: 오늘·다가오는 두 칸. 📌 고정을 누르면 항상 위 작은 창이 되고, 끌어서 옮길 수 있습니다.
- **원형 메뉴**(F27): 펫에 커서를 올리면 반원 6칸(오늘 카드·빠른 실행·폴더 서랍·캡처·작업 목록·잠 안 자기)이 펼쳐지고, 가리킨 칸 이름이 한 곳에 보입니다. 다른 패널이 열려 있으면 겹치지 않는 쪽(위·아래·옆)으로 펼칩니다. 숫자 키로 고르고 Esc로 닫습니다. 칸을 0.3초 꾹 눌러 들면 옆 칸과 자리를 바꿀 수 있고, 순서는 저장됩니다(설정 > 일반에서 처음대로).
  - 허락을 기다리는 작업이 있으면 '작업 목록' 칸에 숫자 배지가 붙습니다. 빼꼼·그 사이 소식·설정은 메뉴 막대에 있습니다.
  - macOS 26 이상에서는 시스템 리퀴드 글래스를, 그 아래에서는 흐림 유리를 씁니다. 투명도는 설정에서 바꿉니다.
- **쓰다듬기·반응**: 좌우로 문지르면 좋아하고, 여러 번 찌르면 삐칩니다. 오래 가만두면 좁니다.
- **여러 마리**: 펫을 여러 마리 두고, 마리마다 받을 알림(Claude Code만, Codex만 등)을 나눌 수 있습니다.
- **받침대**(F27): 곰 발밑 유리 판에 시계·남은 할 일·다음 일정, 오른쪽 끝에 작업 상태 구슬. 설정 '알림 디스플레이 보기'에서 갖다대면(기본)·항상·안 봄, 24시간제, 초 보이기를 고릅니다.
- 펫에서 열린 창(알림, 서랍, 설정 등)은 펫을 끌면 함께 움직입니다.

### AI 에이전트 작업 알림
- 설정 → 작업 알림에서 Claude Code·Codex를 연결하면, 에이전트의 훅(hook)이 Tasky에 상태를 보냅니다.
- **상태 구슬**: 작업이 끝나면(초록)·허락을 기다리면(주황)·실패하면(빨강) 받침대 오른쪽 끝 구슬 색이 바뀝니다. 구슬을 누르면 그 작업의 터미널 앱이 앞으로 오고, 곰을 누르거나 올렸다 떼면 끝남은 지워집니다(허락 대기·실패는 남음).
- **허락이 필요할 때만** 펫 옆에 카드로 알립니다(무엇을 허락할지 명령 앞부분과 함께). 끝남·실패는 알리지 않고, 메뉴 막대 '작업 목록'(세션 카드)에서 봅니다.
- 연결할 때 기존 설정 파일(`~/.claude`, `~/.codex`)을 백업하고 Tasky 항목만 더합니다.
- 훅은 실행 파일 경로를 가리키므로, `.build`를 지웠다면 다시 연결해야 합니다.

### 폴더 서랍
- ⌥ Option을 누른 채 펫에 커서를 올리거나, 원형 메뉴의 '폴더 서랍'으로 엽니다(열기 키는 설정에서 변경).
- 위 칩 줄에서 [최근]·고정 폴더·[+]를 고르고 칼럼으로 탐색합니다. '최근'은 고정 폴더에서 최근 7일 동안 바뀐 파일을 최신 순으로 보여 줍니다. 폴더를 칩 줄에 끌어 놓으면 추가됩니다. 스페이스로 훑어보기(Quick Look), 끌어내기, 끌어 넣기(같은 디스크는 이동, ⌥는 복사)를 지원합니다.
- 삭제는 항상 휴지통으로 갑니다.

### 드롭 변환
파일을 펫 위로 끌고 오면 곰 둘레에 둥근 변환 칸이 원으로 펼쳐지고(F27), 칸에 놓으면 원본은 그대로 두고 옆에 새 파일을 만듭니다. 칸이 7개를 넘으면 안쪽은 형식, 바깥은 동작 두 고리로, 화면 끝에서는 반원으로 펼칩니다. 결과가 원본과 다른 칸(예: PDF→Word '글자만', 표→PDF '단순 표')은 칸에 밝혀 둡니다.

| 종류 | 할 수 있는 일 |
|---|---|
| 이미지 | JPEG·PNG·HEIC·TIFF·PDF로, 긴 변 1920/1280, 용량 줄이기, 위치·촬영 정보 지우기, 배경 지우기, 글자 꺼내기 |
| PDF | 페이지를 PNG·JPG로, 글자만 TXT·Word로, 용량 줄이기, 페이지 나누기, 합치기(여러 개) |
| 영상 | MP4(H.264)·HEVC·MOV로, 720p로 줄이기, 소리만 M4A로, GIF로(앞 10초), 대표 사진 |
| 소리 | M4A·WAV·MP3·AIFF로 |
| 문서 | PDF·DOCX·TXT·RTF·HTML·ODT로 |
| 표 | 엑셀→CSV(시트마다), CSV→엑셀, 단순 표 PDF |
| 압축 | ZIP으로 묶기, 풀기 |

### 싱잉볼 쉼
- 원형 메뉴의 '싱잉볼'을 열고 그릇을 치거나 테두리를 따라 돌리면 소리가 납니다. 녹음 없이 실제 싱잉볼의 배음을 합성합니다.
- 쉬는 동안 작업 알림은 미뤄 두고, 끝나면 '그 사이' 브리핑으로 모아 보여 줍니다.

### 키보드 편의 (기본 꺼짐)
- **한영 전환 키**: Caps Lock·오른쪽 ⌘·오른쪽 ⌥ 중 하나로 한/영을 바로 바꿉니다. Caps Lock은 0.5초 이상 누르면 대문자 고정.
  - 켤 때만 '입력 모니터링' 권한을 요청합니다. 키 입력은 판정에만 쓰고 저장·전송하지 않습니다.
- **키 반복 속도**: 키를 꾹 눌렀을 때 반복이 시작되는 시간과 간격을 시스템 설정보다 빠르게 바꿉니다. 바로 적용되고, '처음 값으로'로 되돌릴 수 있습니다.
- 설정의 키보드 탭 맨 위 **바로 테스트** 칸에서 지금 입력 소스(가/A)와 대문자 고정(⇪)을 보며 바로 쳐 볼 수 있습니다.

### 창 정리 (기본 꺼짐)
- 기본 단축키: ⌃⌥←/→/↑/↓ 반쪽(같은 쪽을 다시 누르면 1/2 → 2/3 → 1/3), ⌃⌥⌘↑ 최대화, ⌃⌥⇧; 가운데, ⌃⌥⌫ 원래대로, ⌃⌥⇧←/↑/↓/→ 4분의 1, ⌃⌥⇧A/S/D 3분의 1, ⌃⌥E/T 3분의 2, ⌃⌥-/= 작게·크게, ⌃⌥⌘←/→ 다른 모니터로.
- ⌃⌥⌘Space 바탕화면 보기: 꾹 누르는 동안 바탕화면, 두 번 누르면 바탕화면에 머묾(다시 누르면 돌아옴).
- 창을 화면 가장자리·모서리로 끌면 미리보기 후 맞춰집니다.
- ⌃⌥만 잠깐 누르고 있으면 지금 쓸 수 있는 단축키 도움말이 화면 가운데에 뜹니다(떼면 사라짐).
- 켤 때만 '손쉬운 사용' 권한을 요청합니다. macOS 시스템 단축키나 다른 앱과 겹치는 키는 등록하지 않고 설정에 '겹침'으로 보여 줍니다.

### 설정
펫 → 원형 메뉴 → 설정. 왼쪽 목록에서 항목을 고릅니다(macOS 시스템 설정과 같은 모양).

| 탭 | 내용 |
|---|---|
| 일반 | 로그인 시 실행, 원형 메뉴 투명도(미리보기), 폴더 서랍 열기 키, 싱잉볼 소리, 알림 디스플레이(받침대) 보기 |
| 펫 | 이 펫에만 적용되는 크기·캐릭터·알려 줄 작업 |
| 작업 알림 | 알림음, Claude Code·Codex 연결 |
| 할 일·일정 | 미리 알림·캘린더 켜기, 저장할 목록, 일정 볼 기간, 할 일 알려 주기 간격, 빠른 실행 단축키 |
| 키보드 | 바로 테스트, 한영 전환, 키 반복 |
| 클립보드 | 기록 켜기, 단축키, 기록 개수 (창에서 📌로 고정하면 검색칸 아래 칩으로) |
| 창 정리 | 켜기·권한, 끌어서 맞추기, 동작별 단축키 |
| 개발자 | `--debug`로 실행했을 때만 보임 |
| 정보 | 버전, 권한 상태 |

### 화면 캡처 (기본 꺼짐)
- ⌃⇧1 영역, ⌃⇧4 창, ⌃⇧5 전체 화면. 찍으면 클립보드에 복사되고 오른쪽 아래에 미리보기가 뜹니다(끌어서 다른 앱에 놓기 가능).
- 미리보기를 누르면 편집 창: 화살표 A, 네모 R, 글씨 T, 모자이크 M, 형광펜 H, 번호 N, 스포트라이트 S, 돋보기 Z, 자르기 C. 그린 것은 눌러서 옮기고 끝점으로 크기를 바꿉니다. ⌘Z 되돌리기, ⌘C 복사, ⌘S 저장(기본 바탕화면, 설정에서 변경).
- 원형 메뉴의 '캡처' 칸을 누르면 오늘 찍은 캡처 띠가 보입니다. 누르면 다시 미리보기(클립보드에도 복사), 아래 버튼으로 바로 찍습니다.
- 편집 창의 '글자 복사'는 이미지 속 한국어·영어 글자를 복사하고, '화면에 고정'은 이미지를 다른 창 위에 띄웁니다(스크롤 크기, ⌥스크롤 투명도, 더블클릭 편집, Esc 닫기).

### 잠 안 자기
메뉴 막대의 곰 아이콘을 오른쪽 클릭하면 메뉴 없이 바로 켜지고 꺼집니다. 켜져 있는 동안 곰이 김 나는 컵을 들고, 화면 꺼짐과 Mac 잠자기를 막습니다. 시간은 왼쪽 클릭 메뉴의 '잠 안 자기'에서 고릅니다(15분~12시간, 영원히). 오른쪽 클릭은 마지막에 고른 시간으로 켜고, 기본은 영원히입니다. Tasky를 끄면 함께 풀립니다.

## 캐릭터: 테디
Tasky의 캐릭터는 3D 곰 **테디** 하나입니다(숨쉬기·깜빡임·커서 따라 고개 돌리기, 상황마다 움직임). 3D 모델은 `~/Library/Application Support/Tasky/Characters/bear3d/model.usdz`에 두면 도형 곰 대신 쓰입니다.

## 권한과 개인정보
- 기본 상태에서는 **어떤 권한도 요청하지 않습니다.**
- 아래 기능은 사용자가 켤 때만 권한을 요청합니다.
  - 한영 전환 키: 입력 모니터링
  - 창 정리: 손쉬운 사용
  - 화면 캡처: 화면 기록
- 모든 데이터(설정, 작업 상태, 성능 기록)는 내 Mac에만 저장하며 밖으로 보내지 않습니다.

### 성능 확인
`--debug`로 실행하면 설정에 '개발자' 탭이 생깁니다.
- CPU, 메모리, 펫이 움직인 프레임 수, 애니메이션 수, 반복해서 하는 일을 1초마다 보여 줍니다.
- '1초마다 기록 남기기'를 켜면 `~/Library/Logs/Tasky/perf-날짜.csv`에 저장됩니다. 성능 문제를 제보할 때 이 파일을 이슈에 붙여 주세요.

### 작업 방식
새 기능은 구현 전에 `intent/<기능>/`에 문서로 합의합니다: `intent.md`(무엇·왜) → `spec.md`(설계) → `plan.md`(파일·순서·검사). 자세한 내용은 [AI-NATIVE-GUIDE.md](AI-NATIVE-GUIDE.md)와 [CLAUDE.md](CLAUDE.md)를 보세요.

- PR 전에 `swift build`와 `--selftest`가 통과해야 합니다.
- 새 반복 작업(타이머)은 `Ticker.every/once`로 만들어 개발자 탭에 보이게 합니다.
