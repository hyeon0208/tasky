# F23 잠 안 자기 — spec
- 작성: 2026-10-30 · 근거: intent.md(승인됨), 아이콘 시안 C2 · 상태: 초안(승인 대기)

## 지금 상태 (코드로 확인)
- 메뉴 막대 항목은 `App.setUpStatusItem`: 18pt 템플릿 곰(`MenuBarIcon.png`), `statusItem.menu`로 왼쪽·오른쪽 클릭 모두 메뉴가 열린다.

## 우려 사항
1. **잠 막기 — 추천: `IOPMAssertionCreateWithName(kIOPMAssertionTypePreventUserIdleDisplaySleep)`** 하나. 화면 꺼짐을 막으면 시스템 잠자기도 함께 막힌다. 끌 때 `IOPMAssertionRelease`. 앱이 끝나면 macOS가 자동으로 풀어 준다(남지 않음).
2. **오른쪽 클릭 — 추천: `statusItem.menu`를 빼고 버튼 `sendAction(on: [.leftMouseUp, .rightMouseUp])`로 받는다.** 왼쪽이면 지금 메뉴를 `statusItem.menu = menu; button.performClick; menu = nil` 방식으로 열고, 오른쪽(또는 ⌃클릭)이면 메뉴를 띄우지 않고 바로 켜기/끄기(꺼져 있으면 고른 시간만큼 켜고, 켜져 있으면 끈다).
3. **아이콘 C2 — 추천: 코드로 그린 템플릿 이미지 23×18.** 곰 그림(`MenuBarIcon.png`) + 오른쪽에 컵·한 손·김 두 줄을 `NSImage(size:flipped:drawingHandler:)`로. 김 움직임은 3프레임(김 없음·낮게·높게)을 3초 주기로 바꿔 끼운다(`Ticker` '잠 안 자기 김', 켜진 동안만, 1초 간격). 컵은 템플릿이라 메뉴 막대 색(검정/흰색)을 따른다(시안의 갈색은 메뉴 막대 아이콘 규칙상 단색으로).
   - 동작 줄이기면 김을 멈춘 프레임 하나.
4. **시간 — 메뉴에 '잠 안 자기' 하위 메뉴: 15분 / 1시간 / 2시간 / 5시간 / 12시간 / 영원히 / 끄기 (사용자 결정).** 고르면 그 시간으로 바로 켜지고, 오른쪽 클릭 켜기는 마지막에 고른 시간(기본 영원히: 끄기 전까지 계속). 남은 시간이 있으면 메뉴 제목에 "(남은 42분)". 끝나면 저절로 꺼짐(`Ticker` 1분 간격으로 확인 대신 `DispatchWorkItem` 하나로 끝 시각에).
5. **저장 — 켜짐 상태는 저장하지 않는다(추정: 다시 실행하면 꺼진 채).** 마지막 고른 시간만 저장.
6. **펫 반응 — 이번엔 없음(사용자 정정: 아이콘으로만).**

## 요구사항
- R1. 오른쪽 클릭으로 메뉴 없이 켜고 끈다. 왼쪽 클릭은 지금 메뉴.
- R2. 켜진 동안 화면·Mac이 잠들지 않고 아이콘이 C2.
- R3. 시간을 고르면 그 뒤 저절로 꺼진다.
