# F17 개발자 옵션 (--debug) — spec
- 작성: 2026-10-28 · 근거: intent.md(승인됨) · 상태: 승인됨(2026-10-28)

## 지금 상태 (코드로 확인)
- 실행 옵션은 `main.swift`에서 `CommandLine.arguments`로 본다(`--selftest`, `--hook`, `--connect`, `--convert`).
- 반복 타이머는 7곳에서 `Timer.scheduledTimer`로 직접 만든다(AgentPanel 1, PetController 3, PetView 2, SingingBowl 1). 그 밖에 `DispatchQueue.main.asyncAfter` 7곳, 키보드 기능의 Dispatch 타이머.
- 설정 탭은 F13의 `SettingsTabs`(탭 배열을 받음).

## 우려 사항
1. **'켜져 있는 타이머 수'를 어떻게 셀지 — 추천: 우리 코드가 만든 타이머만 센다.** macOS는 앱 안의 타이머 목록을 알려 주지 않는다.
   - 추천: `Timer.scheduledTimer` 7곳을 작은 함수 `Ticker.every(...)`/`Ticker.once(...)`로 바꾸고, 함수가 살아 있는 타이머를 약한 참조 목록에 담아 센다. 이름표(예: "깜빡임", "서랍 키")도 함께 보여 줘 어느 것이 도는지 안다.
   - `asyncAfter`·Core Animation 내부 타이머는 세지 않는다(화면에 "우리 타이머만"이라고 적음).
2. **CPU % — 추천: 1초마다 이 앱이 쓴 CPU 시간(`getrusage`의 사용자+시스템 시간)의 늘어난 양 ÷ 1초.** 활성 상태 보기와 같은 뜻(코어 하나 = 100%).
3. **메모리 — 추천: `task_info(TASK_VM_INFO)`의 `phys_footprint`(MB).** 활성 상태 보기의 '메모리' 열과 같은 값이라 비교하기 쉽다.
4. **초당 프레임 — 추천: 펫 창이 실제로 다시 그려진 횟수.** 화면 주사율(`CVDisplayLink`)을 재면 늘 60/120이라 의미가 없다.
   - 펫 몸·얼굴은 Core Animation이 그려 우리 코드가 그리는 횟수를 알 수 없다. 대신 '움직이는 애니메이션 수'(펫 층에 걸린 애니메이션 개수)와 함께, `CADisplayLink`(macOS 14+, 펫 창에 붙임)로 화면이 갱신된 횟수를 보여 준다. 쉬고 있는데 애니메이션이 돌면 낭비를 바로 안다. (추정: 이 둘이 개선에 더 쓸모 있음)
5. **재는 비용 — 추천: 개발자 탭이 열려 있을 때만 1초 간격으로 잰다.** `CADisplayLink`도 그때만 켠다. 탭을 닫거나 다른 탭으로 가면 멈춘다.
6. **로그 파일 — 추천: '기록 남기기'를 켜면 `~/Library/Logs/Kongpod/perf-<날짜>.csv`에 1초마다 한 줄(시각, CPU, 메모리, 프레임, 애니메이션 수, 타이머 수).** 켜 둔 동안은 개발자 탭을 닫아도 계속 잰다. '폴더 열기' 버튼. 기여자는 이 파일을 이슈에 붙인다.

## 요구사항
- R1. `--debug` 없이 실행하면 개발자 탭이 없고, 재는 일도 없다.
- R2. `--debug`면 설정에 '개발자' 탭(아이콘 hammer): CPU %, 메모리 MB, 화면 갱신/초, 움직이는 애니메이션 수, 우리 타이머 수 + 이름 목록. 1초마다 갱신.
- R3. 기록 남기기 켜기·끄기, 로그 폴더 열기.
- R4. 이 앱 자신의 값만, 밖으로 보내지 않는다.

## 설계
- `Debug.swift`(새로): `Debug.isOn`(실행 옵션), `Ticker`(타이머 만들기·세기), `PerfSampler`(CPU·메모리·프레임·애니메이션 수 1초마다, 구독자에 알림, CSV 기록).
- 타이머 7곳을 `Ticker`로 바꾼다(동작 같음).
- `PetController.openSettings()`: `Debug.isOn`이면 탭 배열에 '개발자' 추가. 펫 창(애니메이션 수·프레임을 잴 대상)을 `PerfSampler`에 알려 준다.

## 검증 방법
- 자체 검사: `Ticker`로 만든 타이머 수가 늘고 `invalidate` 후 줄어듦, CPU % 계산(시간 차 ÷ 간격), CSV 한 줄 형식.
- 실제 실행: `--debug`로 띄워 값이 1초마다 바뀌는지는 사용자 확인. 걷기는 없어졌으므로 링을 열고 닫을 때 애니메이션 수가 늘었다 주는지로 본다.
