# F17 개발자 옵션 (--debug)
- 작성: 2026-10-28 · 요청자: 사용자 · 상태: 승인됨(2026-10-28)
- (추정) 표시는 사용자가 아직 확인하지 않은 부분

## 문제
- 오픈소스로 공개하면 다른 사람 컴퓨터에서 느려지거나 메모리가 새는지 알 방법이 필요하다.

## 원하는 결과
- `Kongpod --debug`로 실행하면 설정 창에 '개발자' 탭이 생긴다(사용자 결정). 일반 실행에서는 보이지 않는다.
- 보여 주는 값(1초마다 갱신): CPU %, 메모리(MB), 초당 프레임, 켜져 있는 타이머 수.
- 값을 파일로 남기기 켜기·끄기, 남긴 파일 폴더 열기. (추정)

## 범위
- 포함: 위 네 값, 로그 파일
- 제외: 원격 전송, 충돌 보고

## 제약
- 값은 이 앱 자신의 것만 잰다(다른 앱 정보 없음), 밖으로 보내지 않는다.
- 재는 일 자체가 CPU를 거의 쓰지 않아야 한다(탭이 열려 있을 때만 1초 간격).

## 성공 기준
- [ ] `--debug` 없이 실행하면 '개발자' 탭이 없다
- [ ] `--debug`로 실행하면 네 값이 1초마다 바뀐다
- [ ] 걷기를 켜면 타이머 수·프레임 값이 늘어난 것이 보인다
