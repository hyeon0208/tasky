# F16 클립보드 기록 — spec
- 작성: 2026-10-29 · 근거: intent.md(승인됨) · 상태: 승인됨(2026-10-29)

## 지금 상태
- 클립보드 관련 코드 없음. 전역 단축키도 없음(서랍 키는 펫 위 호버 중에만 확인).
- 펫·패널은 포커스를 뺏지 않는 `FloatingPanel`, 키 입력이 필요한 창은 `keyable`(설정·서랍).

## 우려 사항
1. **⌘⇧C 전역 단축키 — 추천: Carbon `RegisterEventHotKey`.** 권한이 필요 없는 유일한 공식 방법(Maccy·Rectangle도 같은 방식). 다른 앱이 이미 같은 키를 등록했으면 등록이 실패하고, 그때 설정에 "다른 앱이 쓰고 있어요"를 보여 준다. 크롬 개발자 도구·Finder의 ⌘⇧C는 앱 안 단축키라 등록은 성공하지만 그 기능을 가린다(intent 제약대로 설정에 안내).
2. **바뀜 확인 — 추천: 0.5초마다 `NSPasteboard.general.changeCount` 비교(`Ticker`, 이름 '복사한 것 확인하기').** 바뀌었을 때만 내용을 읽는다. 0.5초 동안 두 번 복사하면 앞의 것은 놓친다(Maccy와 같은 한계).
3. **무엇을 기록 — 추천: 글자, 이미지(PNG·TIFF), 파일(경로).** 리치 텍스트는 글자로만. 글자 1MB, 이미지 10MB 넘으면 건너뜀.
   - 기록하지 않음: `org.nspasteboard.ConcealedType`·`TransientType`·`AutoGeneratedType`이 붙은 것, 우리 앱이 기록에서 다시 올린 것(같은 내용이 맨 위로 올라가기만).
   - 같은 내용이 다시 복사되면 새로 쌓지 않고 맨 위로.
4. **저장 — 추천: `Application Support/Tasky/Clipboard/`에 `history.json`(글자·파일 경로·메타) + 이미지는 별도 PNG 파일.** 기본 50개, 설정 10~200. 고정 항목은 개수에 세지 않고 지워지지 않는다. 전체 지우기(고정 제외/포함 선택).
5. **기록 창 — 추천: 커서가 있는 화면 가운데 위쪽, 너비 420.** 맨 위 검색 칸(열자마자 입력 가능) + 목록(최신순, 고정은 맨 위 묶음). 항목 한 줄: 종류 아이콘·앞부분 글자(이미지는 작은 미리보기)·시간. ↑↓ 이동, ↩·클릭 = 그 항목을 클립보드 맨 위로 올리고 창 닫기, ⌘P 고정/풀기, ⌫ 지우기(항목 하나), Esc·바깥 클릭 닫기. 1~9로 바로 고르기.
   - 창은 키를 받아야 하므로 `keyable` 패널을 앞으로 가져온다. 앞 앱의 포커스는 잠깐 넘어오지만 닫으면 원래 앱으로 돌아간다(그래야 바로 ⌘V).
6. **펫 연결 — 추천:** 새로 복사하면 펫이 0.6초 '받았어요' 반응(입벌림) + 머리 위에 짧은 쪽지(글자 앞 20자, 1.5초). 원형 메뉴에 '클립보드' 칸(기록 창 열기). 펫에 끌어다 놓아 서랍 보관은 이번엔 빼고 다음 단계(F2 서랍 쪽 일).
7. **설정 — 추천: 일반 탭 대신 새 '클립보드' 탭(아이콘 doc.on.clipboard):** 켜기(기본 켜짐), 단축키(⌘⇧C 기본, 키 녹화 버튼), 기록 개수, 복사할 때 펫 반응, 전체 지우기, 겹침 안내.

## 요구사항
- R1. ⌘⇧C로 기록 창, 바로 검색, ↩·클릭이면 그 항목이 클립보드 맨 위가 되고 창이 닫힌다.
- R2. 숨김 표시된 복사는 기록하지 않는다. 기록은 내 Mac에만.
- R3. 고정, 하나 지우기, 전체 지우기. 앱을 다시 켜도 남는다.
- R4. 단축키·개수 설정, 등록 실패 안내.

## 설계
- `Clipboard.swift`(새로): `ClipItem`(종류·글자·파일·이미지 파일 이름·시각·고정), `ClipHistory`(순수: 넣기·중복 올리기·개수 자르기·검색), `ClipWatcher`(changeCount 확인·읽기·숨김 판정), `ClipStore`(JSON·이미지 저장), `HotKey`(Carbon 등록·해제), `ClipWindow`(검색·목록·키).
- `PetController`/`App`: 시작 때 감시·단축키, 링 '클립보드' 칸, 복사 반응, 설정 탭.

## 검증 방법
- 자체 검사(`ClipHistory`): 3개 넣으면 최신순 3개, 같은 글자 다시 → 맨 위로·개수 그대로, 개수 넘으면 오래된 것부터(고정은 남음), 검색(대소문자 무시·한글), 숨김 타입 판정, JSON 저장·읽기 왕복(임시 폴더).
- 단축키 등록·창·붙여넣기는 사용자 확인.
