# F16 클립보드 기록
- 작성: 2026-10-28 · 요청자: 사용자 · 상태: 승인됨(2026-10-28)
- (추정) 표시는 사용자가 아직 확인하지 않은 부분
- 참고: /Applications/Maccy.app (오픈소스)

## 문제
- 조금 전에 복사한 것을 다시 쓰려면 원래 자리로 돌아가야 한다.

## 원하는 결과
- 복사한 내용(글자·이미지·파일)을 최근 50개까지 기록(개수는 설정에서).
- ⌘⇧C로 기록 창을 열고 바로 입력해 검색, ↑↓·↩ 또는 클릭으로 고르면 그 항목이 클립보드 맨 위가 되고 창이 닫힌다. 붙여넣기는 사용자가 ⌘V로 한다(사용자 결정). 단축키는 설정에서 바꿀 수 있다(사용자 결정).
- 자주 쓰는 항목은 고정.
- 펫이 방금 복사한 것을 잠깐 들고 있고, 펫을 누르면 같은 기록 창. 펫에 끌어다 놓으면 서랍에 보관.

## 범위
- 포함: 기록·검색·고정·붙여넣기, 펫 연결
- 제외: 기기 간 동기화, 서식 편집

## 제약
- 클립보드는 주기적으로 바뀜만 확인한다(권한 없음). 비밀번호 관리자 등이 '숨김'으로 표시한 내용(org.nspasteboard.ConcealedType·TransientType)은 기록하지 않는다.
- 기록은 내 컴퓨터에만 저장, 전송하지 않는다. 설정에서 전체 지우기.
- 자동 붙여넣기를 하지 않으므로 손쉬운 사용 권한이 필요 없다. ⌘V 안내도 띄우지 않는다.
- ⌘⇧C는 크롬 개발자 도구·Finder '컴퓨터'와 겹친다는 것을 설정에 적는다.

## 성공 기준
- [ ] 글자를 3번 복사한 뒤 ⌘⇧C → 3개가 최신순으로 보인다
- [ ] 검색어를 치면 바로 걸러진다
- [ ] 항목을 ↩ 또는 클릭하면 창이 닫히고, 다른 앱에서 ⌘V 하면 그 항목이 붙는다
- [ ] 숨김 표시된 복사는 기록되지 않는다
- [ ] 앱을 다시 켜도 기록·고정이 남는다
