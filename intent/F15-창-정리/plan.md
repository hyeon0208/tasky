## 순서
1. `SnapMath`: 영역 + 동작 → 사각형, 반쪽 순환(지금 창이 그 반쪽과 2pt 안으로 같으면 다음 비율), 가장자리 판정(5pt, 모서리 우선 20pt), AX↔AppKit 좌표 변환 → 자체 검사 먼저.
2. `HotKey` 여러 등록으로 넓힘 → 클립보드 ⌘⇧C 그대로 동작하는지 빌드·자체 검사.
3. `SystemHotKeys`: `defaults` 도메인 `com.apple.symbolichotkeys`에서 enabled 항목의 (키코드, 수정키) 읽기 → 지금 Mac에서 개수 출력 확인.
4. `AXWindow` + `SnapController` 단축키 동작, 원래대로 기억(`CFHash(창 요소)` 키, 메모리만).
5. 끌어서 맞추기: 전역 마우스 감시(드래그·놓기), 시작 때 커서 아래 창의 위치를 기억해 실제로 움직였을 때만, 미리보기 `FloatingPanel`(클릭 통과·반투명), 놓으면 맞춤. 감시는 Ticker 대신 이벤트라 개발자 탭 대상 아님.
6. 설정 탭·켜기 흐름: 켜면 권한 확인(없으면 요청 + '권한 열기'로 시스템 설정의 손쉬운 사용 칸), 권한 생길 때까지 2초마다 확인(`Ticker` '창 정리 권한 생겼는지 보기', 생기면 멈춤). 겹친 키는 등록 안 함.
7. 빌드·자체 검사 → 독립 검토 → 반영 → 문서·커밋.

## 검사
- 자체 검사: 1440×900에서 왼쪽 반·오른쪽 반·4분의 1·3분의 1·3분의 2 사각형, visibleFrame 원점이 0이 아닐 때, 순환 1/2→2/3→1/3→1/2, 가장자리(왼쪽 3pt → 왼쪽 반, 왼쪽 위 모서리 → 왼쪽 위 4분의 1, 가운데 → 없음), 좌표 왕복(두 번째 모니터 위쪽 배치), 시스템 단축키와 같은 키 → 겹침.
- 사용자 확인: 권한 요청, ⌃⌥← 실제 이동, ⌃⌥⌫ 복귀, 끌기 미리보기, Rectangle 실행 중 '겹침' 표시.
