# F15 창 정리 (Rectangle 방식)
- 작성: 2026-10-28 · 요청자: 사용자 · 상태: 승인됨(2026-10-28)
- (추정) 표시는 사용자가 아직 확인하지 않은 부분
- 참고: /Applications/Rectangle.app 2.0.4 (오픈소스, 라이선스는 spec에서 확인)

## 문제
- 창을 반쪽·3분의 1·최대화로 맞추려면 별도 앱이 필요하다. 펫 하나로 합치고 싶다.

## 원하는 결과
- Rectangle과 같은 방식·같은 기본 단축키(사용자 결정):
  - ⌃⌥←/→/↑/↓ 반쪽, ⌃⌥↩ 최대화, ⌃⌥C 가운데, ⌃⌥⌫ 원래대로, ⌃⌥U/I/J/K 4분의 1, ⌃⌥D/F/G 3분의 1, ⌃⌥E/T 3분의 2, ⌃⌥⌘←/→ 다른 모니터로 (추정: Rectangle 기본값 그대로)
  - 창을 화면 가장자리·모서리로 끌면 미리보기 후 맞춤(스냅).
- 원형 메뉴나 설정에서 단축키를 보고 바꿀 수 있다.

## 범위
- 포함: 위 단축키, 끌어서 맞추기, 원래 크기 기억, 여러 모니터
- 제외: 사용자 정의 배치 저장, 창 간격 세부 조정(다음 단계)

## 제약
- 다른 앱 창을 움직이려면 손쉬운 사용 권한이 필요하다(사용자 결정: 허용). 이 기능을 켤 때만 요청하고, 기본은 꺼짐(사용자 결정).
- 켜더라도 단축키가 겹치지 않아야 한다(사용자 결정). 켤 때 단축키마다 macOS 시스템 단축키, 등록 실패, 같은 단축키를 쓰는 창 정리 앱이 실행 중인지 확인하고, 겹치는 단축키는 등록하지 않고 설정에 '겹침'으로 표시해 다른 키를 고르게 한다. 겹침 확인 방법은 spec에서 정한다. (추정)
- 끌어서 맞추기는 마우스 이벤트를 듣기만 한다. 키 입력은 등록한 단축키만 받는다.
- 코드를 가져오면 라이선스 문구를 남긴다.

## 성공 기준
- [ ] 켜고 권한을 주면 ⌃⌥← 로 앞 창이 화면 왼쪽 반이 된다
- [ ] ⌃⌥⌫ 로 맞추기 전 크기·위치로 돌아간다
- [ ] 창을 왼쪽 가장자리로 끌면 미리보기가 보이고 놓으면 반쪽이 된다
- [ ] 같은 단축키를 이미 쓰는 앱이 켜져 있으면 그 단축키는 등록하지 않고 '겹침'으로 보인다
- [ ] 권한이 없으면 이 기능만 꺼진 채 '권한 열기'가 보인다
