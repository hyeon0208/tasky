# F6 싱잉볼 쉼 — spec
- 작성: 2026-10-22 · 근거: intent.md(승인됨 2026-10-22) · 상태: 승인됨

## 우려 사항 (모두 결정됨)
1. ✅ **여러 펫일 때 쉼의 범위 — 결정:** 한 펫에서 시작해도 모든 펫의 알림을 보류한다. 다른 펫은 그대로 보이되 알림 창·알림음만 멈춘다.
2. ✅ **F8이 아직 없다 — 결정:** F8 전까지는 쉼이 끝날 때 보류된 알림을 기존 '작업 알림' 목록 창으로 보여 준다. F8 구현 시 그 자리를 브리핑으로 바꾼다.
3. ✅ **"깍지가 싱잉볼을 안고 앉는다"의 표현 — 결정:** 지금은 펫 옆 그릇 창과 펫 몸에 겹쳐 그린 작은 그릇으로 표현한다. 실제 앉는 자세는 디자인 에셋 교체 때 다듬는다.
4. ✅ **'승인 대기' 표시 위치 — 결정:** 싱잉볼 창 아래에 "승인을 기다리는 작업 N" 한 줄(소리 없음). 누르면 작업 알림 목록을 연다. 펫 몸 안 콩알 색은 평소처럼 바뀐다.

## 요구사항
- R1. 원형 메뉴 '싱잉볼' 칸만이 시작점이다(제안 말풍선 없음).
- R2. 펫 옆 작은 창: 시간 선택(1·3·5·10분) → 시작 → 남은 시간 표시 → 끝남.
- R3. 그만두기 버튼과 Esc로 언제든 끝낸다.
- R4. 그릇 클릭 = 치는 소리. 그릇 테두리를 따라 커서로 원을 그리면 소리가 이어지고, 일정한 속도일수록 크고 길게 울린다.
- R5. 호흡 안내: 쉬는 동안 펫이 4초 부풀고 6초 줄어든다. 동작 줄이기 설정이면 크기 대신 밝기만 바뀐다.
- R6. 쉬는 동안 끝남·실패 알림은 창·소리 없이 보류. 승인 대기는 우려 4의 방식으로 소리 없이 작게.
- R7. 쉼이 끝나면(시간 종료·그만두기 모두) 보류한 알림을 보여 준다(우려 2).
- R8. 오디오 엔진은 쉬는 동안만 켠다. 다른 앱 소리를 멈추지 않는다. 키보드·마우스 사용량을 보지 않는다(커서 위치는 싱잉볼 창 안에서만 읽는다).

## 설계

### 화면 흐름
1. 원형 메뉴 '싱잉볼' → 펫 옆(펫이 화면 오른쪽이면 왼쪽)에 약 240×300 창.
2. 시작 전: 그릇 그림 + 시간 버튼 4개(1·3·5·10분). 고르면 바로 시작.
3. 쉬는 중: 그릇, 남은 시간(분:초), '그만두기' 버튼, (있으면) "승인을 기다리는 작업 N".
4. 끝: 짧게 세 번 울리고 창을 닫은 뒤 R7.
- 창은 다른 패널들과 같은 `FloatingPanel`(포커스를 뺏지 않음). Esc를 받으려고 클릭하면 키 창이 된다(서랍과 같은 방식). 바깥 클릭으로 닫지 않는다(쉼 중 실수로 끝나지 않게).

### 소리 (새 파일 `SingingBowl.swift`)
- `AVAudioEngine` + `AVAudioSourceNode`로 직접 합성. 녹음 음원 없음.
- 싱잉볼 배음: 기본음(예: 220Hz)과 비정수배 배음 몇 개(약 ×2.7, ×5.1, ×8.2)를 사인파로 합치고, 각 배음에 아주 작은 주파수 차를 둔 쌍을 더해 맥놀이(울렁임)를 만든다.
- 치기: 진폭을 1로 올린 뒤 수 초에 걸쳐 지수 감쇠.
- 문지르기: 창 안 커서의 그릇 중심 기준 각속도를 재서, 일정한 속도로 돌 때 목표 진폭을 올리고, 멈추면 천천히 감쇠.
- 합성 스레드는 진폭 값만 읽는다(메인 스레드가 원자적으로 갱신).

### 호흡 (`PetView`)
- 쉬는 동안 레이어에 10초 주기 키프레임 애니메이션(0→4초 확대 1.08배, 4→10초 원래 크기). 동작 줄이기면 같은 주기로 밝기만.
- 펫 몸에 작은 그릇을 겹쳐 그리는 `holdingBowl` 상태(우려 3).

### 알림 보류 (`App` / `PetController`)
- `App.resting`(전역, 우려 1). 쉬는 동안 `agents.onChange`에서:
  - 끝남·실패 → 알림 창·소리 없이 보류 목록에 쌓음(세션 상태 자체는 평소처럼 갱신).
  - 승인 대기 → 싱잉볼 창의 한 줄만 갱신, 소리 없음.
- 쉼이 끝나면 보류 목록이 있으면 작업 알림 목록 창을 연다(우려 2).

## 바뀌는 파일
- 새로: `SingingBowl.swift`(합성 엔진 + 싱잉볼 창)
- 수정: `PetController.swift`(원형 메뉴 칸 연결, 쉼 시작·종료, 알림 보류), `PetView.swift`(호흡·그릇 표시), `Geometry.swift`(자체 검사 추가)

## 검증 방법
- 자체 검사: 각속도 → 목표 진폭 계산(일정한 원 운동은 오르고 멈추면 내려감), 보류 규칙(끝남·실패 보류, 승인 대기 통과), 남은 시간 계산.
- 실행 확인: 짧은 시간(테스트용 5초)으로 시작~끝 흐름, 오디오 엔진이 끝나면 멈춤(`engine.isRunning`).
- 화면·소리의 실제 느낌은 사용자 확인 필요(제가 직접 보고 들을 수 없음).
