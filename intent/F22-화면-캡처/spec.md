- 단축키 설정 화면: F15 `snapSettings()`(PetController.swift:1024)에 동작별 키 기록 버튼, 겹침 표시, 권한 상태 줄이 있다.

- `scripts/make-app.sh`로 `dist/Tasky.app`(직접 서명)을 만든다(1950626). 화면 기록 권한은 앱에 붙는다.

## 우려 사항
1. **화면 기록 권한이 누구에게 붙는지.** 번들이 아닌 실행 파일을 터미널에서 띄우면, 권한이 Tasky가 아니라 터미널 앱에 붙을 수 있다(추정). 권한 확인은 `CGPreflightScreenCaptureAccess()`, 요청은 `CGRequestScreenCaptureAccess()`. 권한이 없으면 메뉴에서 "화면 기록 권한이 필요해요 — 권한 열기"(`Privacy_ScreenCapture`)를 보여 준다. 번들 문제는 이미 미뤄 둔 '.app 번들' 작업과 함께 푼다.
2. **캡처 호출 — `/usr/sbin/screencapture`를 `Process`로 부른다.** 결과는 임시 파일(`NSTemporaryDirectory()/tasky-cap-*.png`)로 받아 읽은 뒤 지운다.

   | 동작 | 옵션 |
   |---|---|
   | 영역 | `-i -s -x` |
   | 창 | `-i -w -o -x` |
   | 전체 | `-x` (마우스가 있는 화면 하나, `-D`) |
   | 반복 촬영(스크롤·픽셀 자) | `-R x,y,w,h -x` |

   ESC로 취소하면 파일이 생기지 않으니 조용히 끝낸다. 호출은 백그라운드에서 하고 결과만 메인으로 넘긴다.
3. **스크롤 캡처 — 반자동.**
   - 먼저 `-i -s`로 영역을 고르게 한다.
   - 그다음 영역 테두리와 "스크롤하세요 · 끝나면 클릭/Enter" 안내를 띄운다(마우스 통과 패널).
   - 0.3초마다 `-R`로 그 영역을 찍는다.
   - 앞 장의 아래쪽 띠(약 40px)가 새 장의 어디에 있는지 행 단위 픽셀 비교로 찾고, 새로 생긴 부분만 붙인다. 같은 장(변화 없음)은 버린다.
   - 위로 되돌아간 장이나 못 맞춘 장은 건너뛴다.
   - 최대 높이는 20000px로 둔다.
   - 우리 테두리가 찍히지 않도록, 테두리는 영역 바깥에 그린다.
   - Tasky가 스크롤하지 않는다. 사용자가 스크롤한다(자동 스크롤에는 손쉬운 사용 권한이 필요).
4. **픽셀 자 — 멈춘 화면.** 마우스가 있는 화면을 한 장 찍어 전체 화면 패널에 그대로 띄운다. 그 위에서 마우스 드래그로 가로·세로 거리를 잰다. 숫자는 실제 픽셀(이미지 픽셀 = 포인트 × `backingScaleFactor`)로 보여 준다. ⌘C를 누르면 숫자를 복사하고, ESC를 누르면 닫는다. Shottr처럼 경계를 자동으로 찾아 붙는 기능은 이번에 넣지 않는다(드래그한 대로 잰다).
5. **미리보기.**
   - 화면 오른쪽 아래에 썸네일 패널(폭 약 200pt)을 띄우고, 6초 뒤 사라진다.
   - 마우스를 올리면 사라지지 않고 기다린다.
   - 누르면 편집 창이 열린다.
   - 끌어서 다른 앱이나 서랍에 놓을 수 있다(파일로 넘김).
   - 새 캡처가 오면 앞의 미리보기를 바꾼다(쌓지 않음).
6. **편집 창 — 원본 이미지 + 도형 목록.** 도형마다 종류, 좌표, 색을 갖는다. 그리기는 `NSView.draw`에서 원본 위에 차례로 그린다.
   - 되돌리기: 목록에서 마지막 하나를 빼고, `UndoManager`로 ⌘Z/⇧⌘Z를 처리한다.
   - 결과 만들기: 원본 크기의 비트맵에 같은 순서로 그린다. 이걸 복사(⌘C)하거나 PNG로 저장(⌘S)한다.
   - 도구별 그리는 방법:

   | 도구 | 그리는 방법 |
   |---|---|
   | 화살표 | 선 + 삼각 머리 |
   | 네모 | 테두리만 |
   | 글씨 | 누른 곳에 입력칸을 띄우고, 끝나면 도형으로 바꿈 |
   | 모자이크 | 그 영역을 `CIPixellate`로 처리(원본에서 계산) |
   | 형광펜 | 반투명 굵은 선 |
   | 번호 스티커 | 동그라미 + 1부터 자동 증가 |
   | 스포트라이트 | 고른 영역 밖을 반투명 검정으로 덮음. 여러 개면 합침 |
   | 돋보기 | 원으로 고른 부분을 2배로 확대해 옆 원에 그리고, 두 원을 선으로 이음. 확대 원은 끌어서 옮김 |
   | 자르기 | 도형이 아니라 결과의 범위를 바꿈 |

   - 위쪽 도구 막대(아이콘 + 단축 키 A/R/T/M/H/N/S/Z/C)와 색 5개(빨강·노랑·초록·파랑·검정)를 둔다. 굵기는 고정이다.
   - 고른 도형을 옮기거나 지우는 기능은 이번에 넣지 않는다(되돌리기로 대신). (추정: 가장 자주 쓰는 흐름은 그리고 → 틀리면 되돌리기)
7. **글자 인식.** 편집 창의 '글자 복사' 버튼. `VNRecognizeTextRequest`(정확도 높음, 언어 ko-KR·en-US)로 인식해, 줄마다 이어 붙여 클립보드에 넣는다. 끝나면 "N줄 복사됨"을 표시한다.
8. **화면에 고정.** 편집 창의 '고정' 버튼을 누르면 결과 이미지를 테두리 없는 떠 있는 창(`.floating`, 모든 Space)에 띄운다.
   - 끌어서 옮길 수 있다.
   - 스크롤하면 크기가 바뀐다.
   - ⌥스크롤로 투명도를 바꾼다.
   - 더블클릭하면 편집 창으로 돌아가고, ESC를 누르면 닫힌다.
   - 여러 개를 띄울 수 있다. 고정 상태는 저장하지 않는다.
9. **저장.**
   - 기본 폴더는 `~/Desktop`이고, 이름은 `Tasky 캡처 2026-10-30 14.05.12.png`이다. 이름이 겹치면 ` 2`를 붙인다.
   - 폴더는 설정에서 바꿀 수 있다(`NSOpenPanel`로 폴더를 고름).
   - 저장한 뒤에는 Finder에서 보이게 하지 않고, 편집 창에 "저장됨"만 잠깐 보여 준다.
10. **단축키·설정 — 새 설정 탭 '화면 캡처'.**
    - 기능 켜기·끄기를 둔다. 기본은 꺼짐이고, 켤 때 권한을 요청한다. (추정: 다른 권한 기능과 같게)
    - 동작 5개마다 키 기록 버튼을 두고, 겹침을 표시한다. F15 방식을 재사용한다.
    - 저장 폴더를 고를 수 있다.
    - 권한 상태 줄을 둔다.
    - 단축키는 `HotKey` id 200~204를 쓴다.
    - 메뉴 막대 메뉴에 '화면 캡처' 하위 메뉴를 두고, 동작 5개를 단축키와 함께 표시한다.

## 요구사항
- R1. 단축키나 메뉴로 영역·창·전체 캡처를 하면, 클립보드에 복사되고 미리보기가 뜬다.
- R2. 미리보기를 누르면 편집 창이 열린다. 도구 9개, 되돌리기, ⌘C, ⌘S가 동작한다.
- R3. 스크롤 캡처는 이음매가 맞는 긴 이미지 한 장을 만든다.
- R4. 픽셀 자는 실제 픽셀 거리를 보여 준다.
- R5. 글자 인식과 화면에 고정이 동작한다.
- R6. 권한이 없으면 안내를 띄우고 권한을 열 수 있다.

## 설계 (새 파일)
- `Capture.swift`: `Capture`(screencapture 호출, 권한, 저장 이름, 단축키 등록)와 `CapturePreview`(미리보기 패널).
- `CaptureEditor.swift`: 편집 창, 도형 모델, 그리기와 결과 만들기, 글자 인식, 고정 창.
- `ScrollStitch.swift`: 반복 촬영과 이어 붙이기(순수 함수 `overlap(prev:next:) -> Int?`를 분리해 자체 검사).
- `PixelRuler.swift`: 멈춘 화면 패널과 거리 재기.
- `PetController.swift`: 메뉴 하위 메뉴, 설정 탭 연결.

## 검증 방법
- **자체 검사:**
  - 저장 이름 형식과 겹칠 때 붙는 번호.
  - 이어 붙이기: 합성 이미지 두 장(겹침 120px)에서 겹침이 120으로 나오는지, 겹침이 없으면 nil인지.
  - 픽셀 거리: 배율 2에서 포인트 100은 200px.
  - 결과 만들기: 화살표 하나를 그린 결과가 원본 크기와 같고, 그 자리 픽셀이 바뀌는지.
  - 글자 인식: 코드로 그린 "Tasky 캡처" 이미지에서 글자가 나오는지.
- **실행 확인 (내가 할 수 있는 것):**
  - `screencapture -R`로 임시 파일이 생기는지.
  - 권한 없을 때 `CGPreflightScreenCaptureAccess`가 false인지.
- **사용자 확인:** 영역 선택, 편집 창 손맛, 스크롤 캡처 품질, 미리보기 위치.
