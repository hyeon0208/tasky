# F22 화면 캡처 — intent
- 작성: 2026-10-30 · 상태: 승인 대기

## 무엇
단축키나 메뉴로 화면을 캡처한다(영역·창·전체·스크롤). 캡처하면 클립보드에 복사되고 화면 구석에 미리보기가 뜬다. 미리보기를 누르면 Tasky 편집 창이 열려 표시를 더한 뒤 복사·저장한다. 멈춘 화면 위에서 재는 픽셀 자도 있다.

## 왜
캡처하고 간단히 표시하는 일을 다른 앱 없이 바로 하고 싶다(사용자 요청).

## 제약
- 다른 앱 이름을 UI에 쓰거나 안내하지 않는다.
- 새 권한 '화면 기록'을 쓴다(사용자 결정 2026-10-30). 캡처 기능을 처음 쓸 때만 요청한다.
- 단축키는 기존 `HotKey`(`RegisterEventHotKey`)를 쓴다. 키 입력을 엿보지 않으므로 입력 모니터링·손쉬운 사용 권한이 필요 없다.
- 이미지는 로컬에만 둔다. 사용자가 저장할 때만 파일로 남긴다.

## 결정
- 방식 A': 캡처는 macOS `screencapture`를 불러 쓴다. Tasky는 편집 창, 픽셀 자 화면, 스크롤 이어 붙이기만 만든다. ScreenCaptureKit 직접 사용(B)은 영역 선택 화면이 아쉬울 때 다시 정한다. 사용자 결정 2026-10-30
- 찍은 뒤: 클립보드에 복사하고 구석에 미리보기를 띄운다(몇 초 뒤 사라짐). 미리보기를 누르면 편집 창이 열린다. 사용자 결정 2026-10-30
- 편집 도구: 화살표, 네모, 글씨, 모자이크, 자르기, 형광펜, 번호 스티커 ①②③, 스포트라이트, 돋보기(원으로 고른 부분을 확대해 선으로 연결). 되돌리기, ⌘C 복사, ⌘S 저장. 색은 몇 가지 중에서 고르고 굵기는 하나로 고정. 사용자 결정 2026-10-30
- 부가 기능: 글자 인식(Vision, 추가 권한 없음), 화면에 고정(떠 있는 창). 사용자 결정 2026-10-30
- 스크롤 캡처: 고른 영역을 반복해서 찍고 겹치는 부분을 찾아 한 장으로 잇는다. 사용자 결정 2026-10-30
- 픽셀 자: 지금 화면을 한 장 찍어 멈춘 채로 띄우고, 그 위에서 거리(px)를 잰다. 사용자 결정 2026-10-30
- 시작 방법: 메뉴 막대 메뉴 + 전역 단축키. 기본 단축키는 아래와 같고, 설정에서 바꾸거나 끌 수 있다. 사용자 결정 2026-10-30
  - ⌃⇧1 영역
  - ⌃⇧2 스크롤
  - ⌃⇧3 픽셀 자
  - ⌃⇧4 창
  - ⌃⇧5 전체
- 저장: ⌘S를 누르면 바탕화면에 `Tasky 캡처 YYYY-MM-DD HH.mm.ss.png`로 저장한다. 폴더는 설정에서 바꿀 수 있다. 사용자 결정 2026-10-30
- 범위 밖(나중에): 배경·여백 꾸미기, 색 추출, 영역을 고르는 중의 돋보기·좌표 표시(B 방식에서 가능), 링 메뉴 캡처 칸.

## 성공 기준
- 단축키를 누르고 영역을 고르면, 클립보드에 이미지가 들어가고 미리보기가 뜬다.
- 미리보기를 누르면 편집 창이 열린다. 각 도구로 그리고 되돌릴 수 있다. ⌘C로 편집 결과를 복사하고, ⌘S로 바탕화면에 PNG를 저장한다.
- 스크롤 캡처를 하면 이음매가 어긋나지 않은 긴 이미지 한 장이 나온다.
- 픽셀 자로 잰 거리가 실제 픽셀 수와 맞는다(레티나 배율 반영).
- 글자 인식은 한국어와 영어 글자를 복사한다. 화면에 고정한 창은 다른 창 위에 떠 있다.
- 화면 기록 권한이 없으면 권한을 켜는 방법을 알려 주고, 기능을 조용히 실패시키지 않는다.
