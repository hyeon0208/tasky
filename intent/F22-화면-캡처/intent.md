# F22 화면 캡처 — intent
- 작성: 2026-10-30 · 상태: 초안(질문 대기)

## 무엇
자체 단축키로 화면(영역·창·전체)을 캡처하고, 바로 뜨는 편집 창에서 그리기·글자·화살표·가리기 등을 한 뒤 복사·저장한다.

## 왜
캡처 후 간단한 표시를 다른 앱 없이 바로 하고 싶다(사용자 요청).

## 제약
- 다른 앱 이름을 UI에 쓰거나 안내하지 않는다.
- 화면 캡처는 macOS '화면 기록' 권한이 필요하다(새 권한 → 사용자 결정 필요). 켤 때만 요청.
- 캡처 이미지는 로컬에만. 단축키는 기존 `HotKey`, 겹침 표시는 F15 방식(추정).

## 성공 기준 (추정)
- 단축키 → 영역 선택 → 편집 창 → ⌘C 복사 / ⌘S 저장.

## 열린 질문
- 화면 기록 권한 사용 승인, 첫 범위(영역·창·전체 / 편집 도구 종류), 기본 단축키
