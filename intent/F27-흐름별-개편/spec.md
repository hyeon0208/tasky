- 지금 `AgentBadgeView` 구슬을 받침대 오른쪽 끝으로 옮김. 구슬을 누르면 그 터미널로 가는 동작은 유지하므로, 구슬 칸만 마우스를 받음.
- 설정 '알림 디스플레이 보기': `hover`(기본) / `always` / `never`. hover는 곰에 올렸을 때만 보여 줌. never면 구슬도 숨김.

### 4. 오늘 카드 B
- 할 일·일정·AI 작업 세 덩어리로 나눔. 입력칸 문구는 "할 일 또는 일정 추가".
- 일정은 오늘부터 N일 뒤까지 보여 줌. 설정 '일정 볼 기간' 1~7, 기본 7.
- 일정 알림은 시작 60분 전, 30분 전, 정각. 순수 함수 `TaskLogic.eventAlerts(events, now, sent)`가 띄울 (항목, 단계)를 돌려줌.
  - 보낸 키는 `id@시작시각#단계`로 기록해 한 번씩만 띄움.
  - 앱이 늦게 켜져 이미 지난 단계는 건너뛰고 가장 최근 단계 하나만 띄움(추정).
- 할 일 알림은 N분마다 남은 할 일을 패널 하나로 보여 줌("남은 할 일 3개 · 첫 항목").
  - 설정 '할 일 알려 주기 간격': 끄기 / 15·30·60·120분, 기본 60.
  - 남은 할 일이 0이면 띄우지 않음.
  - 기존 '정해진 시각 할 일 알림'은 일정 알림과 같은 길(정각)로 유지(추정).

### 7. AI 작업
- `presentAlert`는 승인 대기(내 차례)일 때만 B 카드("무엇을 허락할지" 보여 줌)를 띄움.
  - 끝남·실패는 알리지 않고 상태 구슬과 목록에만 반영.
  - 판정은 순수 함수로 빼서 자체 검사함.
- 메뉴 막대 '작업 목록'은 A(세션 카드 스택)로 다시 그림.
- 무엇을 허락할지는 훅 payload의 `tool_name`·`tool_input` 요약(명령 앞부분 80자)으로 보여 줌. 지금 payload에 있는지는 plan 전에 확인(추정).

### 8. 폴더 서랍 A + 최근
- NSBrowser 칼럼은 그대로 두고, 위에 칩 줄을 둠: [최근] [고정 폴더…] [+].
  - 칩을 누르면 첫 칼럼의 루트가 바뀜.
  - '최근'은 고정 폴더들 아래 최근 7일 동안 바뀐 파일을 최신 순으로 한 칼럼 목록에 보여 줌. 폴더 이름도 함께 보여 줌.
- 최근 목록은 `FileManager` 열거로 만듦: 깊이 3, 숨김 파일 제외, 최대 200개, 백그라운드에서 만들고 캐시함.
- 서랍을 여는 방식과 파일 넣는 방식은 바꾸지 않음.

### 9. 원형 변환 (새 `ConvertWheel` 패널)
- 파일을 끌고 곰에 들어오면 곰 위에 비활성 패널을 띄워 둥근 부채꼴 칸을 그림.
  - 칸이 7개 이하면 고리 하나, 넘으면 안쪽(형식)과 바깥(동작) 두 고리.
  - 곰이 화면 가장자리에 있어 원이 잘리면 반원으로 그림.
  - 가운데 원에는 썸네일·용량을, 칸에 올리면 결과 설명을 보여 줌.
  - 놓으면 진행 링을 보여 주고, 원 밖에서 놓으면 취소.
- 맞추기(어느 칸 위인지)는 순수 함수 `WheelMath.slot(point, layout)`로 만들고 자체 검사함.
- `ConvertOp`에 추가하는 항목:

| 종류 | 새 항목 | 방법 |
|---|---|---|
| 사진 | toTIFF, imageToPDF(1장도) | ImageIO, PDFKit |
| PDF | pdfToJPG, pdfToText, pdfShrink, pdfSplit, pdfToDOCX(글자만) | PDFKit 렌더·`string`, Quartz 필터, textutil |
| 문서 | docToODT | textutil |
| 표 | csvToXLSX, sheetToPDF(단순 표) | 최소 OOXML을 직접 써서 zip(기존 `zip` 경로), 표를 그려 PDF |
| 영상 | toMOV, posterFrame | AVAssetExportSession, AVAssetImageGenerator |
| 오디오 | toAIFF | AVAudioFile |

- 칸에 넣을 형식/동작 구분과 짧은 설명("글자만", "단순 표")은 `ConvertOp`의 속성으로 둠.
- 원본과 같은 형식의 칸은 빼는 규칙을 모든 종류에 적용함.
- 새 항목마다 `--convert`로 실제 파일을 만들어 확인함.

### 10~12. 캡처 띠·클립보드·창 정리
- 10: 원형 메뉴 '캡처' 칸을 누르면, 오늘 찍은 캡처를 썸네일 띠(C)로 보여 줌. 캡처 저장 폴더에서 오늘 날짜 파일을 찾음.
- 11: 클립보드 창을 B 검색 목록으로 다시 그리고, 고정 항목은 위쪽 칩 줄(C)로 보여 줌. 고정 버튼은 항목마다 둠. `pinned`는 이미 있음.
- 12: ⌃⌥를 누르고 있으면 단축키 도움말 패널이 뜸.
  - 감지는 `NSEvent.addGlobalMonitorForEvents(.flagsChanged)`로 하는데, 이건 창 정리가 이미 받은 손쉬운 사용 권한 안에서만 됨.
  - 창 정리가 켜져 있을 때만 동작하고, 키를 저장하지 않음.

## 우려 사항
1. **집중 모드 확인이 막힐 수 있다.**
   - `INFocusStatusCenter`는 Focus Status 기능(entitlement)과 프로비저닝이 필요해서, 지금처럼 ad-hoc 서명이면 권한을 요청할 수 없을 가능성이 높다(추정, 1단계에서 실제 앱으로 확인).
   - 대안 a: `~/Library/DoNotDisturb/DB/Assertions.json` 읽기 — 전체 디스크 접근 권한이 필요하고 파일 형식도 문서화되지 않아 비추천.
   - 대안 b: Tasky 설정에 '알림 잠시 멈춤' 스위치(메뉴 막대에서도 켜고 끔).
   - 막히면 b를 추천하고 사용자에게 묻는다.
2. **알림이 늘어난다.** 일정 하나에 3번, 할 일은 N분마다 뜬다. 한 번에 하나만 띄우고, 같은 일정의 이전 단계 패널이 떠 있으면 새 단계로 바꿔 끼운다(쌓지 않음).
3. **원형 변환은 드래그 중에 패널을 띄운다.**
   - 드래그 대상은 지금 곰 창(PetView)이라, 원이 곰 창 밖까지 커지면 그 영역에서는 드롭을 받지 못한다.
   - 그래서 원 패널 자체를 드래그 대상으로 등록한다. 마우스 통과를 끄고, 드래그가 끝나면 닫는다.
4. **원형 메뉴 6칸 구성.** 7차 A 시안의 칸은 오늘 카드·빠른 실행·폴더 서랍·캡처·싱잉볼·잠 안 자기인데, 싱잉볼은 꺼 두기로 했다(13번). 빈 칸은 '작업 목록'으로 채우기를 추천(승인 대기 외 작업은 목록에서만 보므로 가까운 입구가 필요). 지금 칸에서 빠지는 설정은 메뉴 막대에 이미 있고, 빼꼼·그 사이 N건(있을 때만)은 메뉴 막대에 추가한다(추정: 사용자가 원하는 위치인지 확인).
5. **양이 많다.** 단계마다 빌드·자체 검사·앱 실행을 하고, 사용자가 화면으로 확인한다.
   1. 알림 패널 C + 일정·할 일 알림 시각 + 집중 모드 + AI 승인만 알림(로직 중심, 자체 검사 가능)
   2. 받침대·상태 구슬 + 알약 + 원형 메뉴
   3. 오늘 카드 + 빠른 실행 + 할 일 창
   4. 원형 변환 + 새 변환 항목
   5. 서랍 최근 + 캡처 띠 + 클립보드 + 창 정리 도움말 + 작업 목록 A
6. **HTML 시안과 AppKit은 다르다.** 유리 질감·블러는 `NSVisualEffectView`/`NSGlassEffectView`로 맞추고, 단계마다 시안과 다른 점을 보고한다.
