# F3 드롭 변환
- 작성: 2026-10-22 (소급 작성) · 요청자: 사용자 · 상태: 구현됨
- 성공 기준 표시: ✅ 확인함 · ❓ 화면에서 미확인

## 문제
파일 형식을 바꾸려면 별도 앱을 찾아 열어야 한다.

## 원하는 결과
- 펫에 파일을 끌어다 대면 형식에 맞는 변환 칸이 펼쳐지고, 놓으면 변환된다.
- 다양한 확장자(docx·hwp·pptx·xlsx·MP3·압축 포함)를 지원한다.

## 범위
- 포함: 이미지(JPEG·PNG·HEIC, 크기·용량, 정보 지우기, 배경 지우기, 글자 꺼내기, PDF로), PDF(PNG, 합치기), 영상(MP4·HEVC·720p·M4A·GIF·MP3), 오디오(M4A·WAV·MP3), 문서(docx·doc·rtf·odt·html·txt ↔ PDF·DOCX·TXT·RTF·HTML), xlsx→CSV, ZIP 압축, 압축 풀기
- 제외: hwp·pptx(LibreOffice 필요, 결정 대기), 다른 앱 안내·홍보

## 제약
- 원본을 바꾸지 않고 `이름 (깍지).확장자`로 저장. macOS 기본 기능 우선. MP3는 ffmpeg가 있을 때만.

## 성공 기준
- ✅ 실제 파일로 확인: 이미지 전 항목(배경 지우기 제외), PDF, MP4·720p·GIF, M4A·WAV·MP3, 문서 변환, xlsx→CSV(한글·따옴표·빈칸), ZIP·압축 풀기, 원본 해시 불변
- ❓ 배경 지우기(인물 사진), HEVC, 펫에 끌어 놓는 실제 동작

## 열린 질문
- hwp·pptx를 위해 LibreOffice를 쓸지
- 엑셀 날짜·수식을 서식대로 내보낼지(지금은 저장된 숫자)
