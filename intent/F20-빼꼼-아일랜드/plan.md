## 순서
1. `Geometry.islandFrame` + 자체 검사 먼저(왼·오·아래·구석, 펼침 같은 끝 고정, 작은 화면 1024×640 안에 들어감).
2. `PetView.island` 그리기(2D 캐릭터로 먼저) → `place` 연결, 접힘/펼침 전환.
3. 3D 곰 `compact` → `--render-bear`에 알약 크기 한 장 추가해 얼굴이 보이는지 확인.
4. 내용: 구슬 점(최대 3 + 개수), 펼침 시계·작업 한 줄(내 차례 > 실패 > 끝남 > 일하는 중 N개), 새 알림 테두리·3초 펼침. 시계·구슬 패널 숨김.
5. 끌어내기·링·알림 카드 위치 확인.
6. 빌드(종료 코드 확인)·자체 검사 → 독립 검토 → 반영 → 문서·커밋·푸시.

## 검사
- 자체 검사: 1440×900에서 각 dock의 접힘/펼침 사각형, 펼침이 같은 끝에 붙는지, 구석 → 세로 알약·아래 40pt, 1024×640에서 화면 안.
- `--render-bear`: compact 한 장.
- 사용자 확인: 알약 모습, 호버 펼침, 새 알림 테두리·펼침, 끌어내기, 링 열림 위치.
