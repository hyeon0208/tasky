## 문제
- 지금 빼꼼은 펫 몸 일부가 화면 끝에 걸쳐 있을 뿐이라 어색하고, 숨어 있는 동안 시계·작업 구슬 같은 정보가 안 보인다.

## 원하는 결과
- 펫을 화면 옆 끝에 두면 Dynamic Island 같은 세로 알약(검은색)이 화면 끝에 붙는다.
  - 평소: 작은 곰 + 작업 구슬(색 점)
  - 커서를 올리면: 옆으로 펼쳐져 곰 + 시계 + 작업 요약
  - 알림: 펼친 채로 한 줄 알림, 누르면 작업 목록
- 알약에서 끌어내면 다시 보통 펫이 된다. (추정)

## 범위

- 제외: 위쪽 끝(메뉴 막대와 겹침)

- 알약은 화면을 최소로 가린다(평소 폭 40pt 안팎, 추정).
