## 문제
- 지금 빼꼼은 펫 몸 일부가 화면 끝에 걸쳐 있을 뿐이라 어색하고, 숨어 있는 동안 시계·작업 구슬 같은 정보가 안 보인다.

## 원하는 결과
- 펫을 화면 옆 끝에 두면 Dynamic Island 같은 세로 알약(검은색)이 화면 끝에 붙는다.
  - 평소: 작은 곰 + 작업 구슬(색 점)
  - 커서를 올리면: 옆으로 펼쳐져 곰 + 시계 + 작업 요약
  - 알림: 펼친 채로 한 줄 알림, 누르면 작업 목록
- 알약에서 끌어내면 다시 보통 펫이 된다. (추정)

## 범위
- 포함: 왼쪽·오른쪽 끝 빼꼼(추정: 아래 끝·구석도 같은 알약을 가로로)
- 제외: 위쪽 끝(메뉴 막대와 겹침)

## 제약
- 포커스를 뺏지 않는 투명 패널. 알약 안의 곰은 움직임 끄기 설정을 따른다.
- 알약은 화면을 최소로 가린다(평소 폭 40pt 안팎, 추정).

## 성공 기준 (추정)
- [ ] 펫을 오른쪽 끝으로 끌어 놓으면 알약으로 바뀐다
- [ ] 커서를 올리면 0.2초 안에 펼쳐지고, 떠나면 접힌다
- [ ] 작업 상태가 바뀌면 알약 안 구슬 색이 바뀐다
- [ ] 알약을 끌어내면 보통 펫으로 돌아온다
