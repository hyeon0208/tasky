# F20 빼꼼 아일랜드 — spec
- 작성: 2026-10-29 · 근거: intent.md(승인됨), 시안 C안 · 상태: 승인됨(2026-10-29)

## 지금 상태 (코드로 확인)
- `dock`(free·left·right·bottom·bottomLeft·bottomRight): 놓은 자리가 가장자리 24pt 안이면 붙음(`Geometry.dock`), `Geometry.frame`이 펫 창을 화면 밖으로 밀어 몸 38%만 보이게. 호버하면 0.3초 뒤 더 내밂(`out: 1`).
- 펫 창 안에는 `PetView`(+3D면 `Pet3DView`). 시계·구슬은 펫 위 자식 패널.
- 링은 `dock`에 맞춘 반원/부채꼴로 열림.

## 우려 사항
1. **알약을 어디에 그리나 — 추천: 펫 창 자체를 알약으로 바꾼다.** 붙으면 펫 창 크기를 알약 크기로 줄이고 화면 끝에서 4pt 안쪽에 둔다. 새 창을 만들지 않으니 클릭·끌기·파일 드롭·링·알림 카드가 지금 코드 그대로 동작한다. `PetView`에 `island: IslandStyle?`를 두어 있으면 검은 알약 배경 + 작은 곰 + 내용을 그린다.
2. **크기 — 추천:**
   - 세로(왼·오): 접힘 44×104(곰 32 + 구슬 점 최대 3), 펼침 210×112(곰 52 + 시계 + 작업 한 줄)
   - 가로(아래): 접힘 104×44(곰 + 점 옆으로), 펼침 240×64
   - 펼침/접힘은 0.2초 ease-out(동작 줄이기면 바로). 펼칠 때 화면 끝은 붙은 채로 안쪽으로 커진다.
3. **곰 — 추천: 같은 `Pet3DView`를 작은 칸에 넣고 `compact = true`.** 몸 움직임(기울기·뛰기·구르기)은 끄고 고개·눈·귀만. 카메라를 머리 쪽으로 당겨 얼굴이 크게 보이게. 움직임 끄기면 가만히. 2D 캐릭터·콩깍지 펫은 그 그림을 축소해 넣는다.
4. **내용 — 추천:**
   - 구슬 점: `BeadModel` 결과의 색(일하는 중 파랑·내 차례 주황·끝남 초록·실패 빨강), 최대 3 + 넘치면 마지막 점 대신 숫자.
   - 펼침: 시계(`ClockMode.text`, 설정을 따름) + 작업 한 줄(가장 급한 것: 내 차례 > 실패 > 끝남 > 일하는 중 'N개').
   - 알림(내 차례·실패·끝남이 새로 옴): 알약 테두리에 상태 색 2pt + 3초 펼침. 누르면 지금처럼 링(첫 칸 '작업 알림')이 열린다.
   - 붙어 있는 동안 펫 위 시계·구슬 패널은 숨긴다(알약 안에 있으므로).
5. **빼고 돌아가기:** 알약을 끌면 끄는 순간 보통 펫 크기로 돌아가고(커서는 몸 가운데), 놓은 자리가 가장자리가 아니면 free. 링의 '빼꼼 그만'도 그대로.
6. **구석:** `bottomLeft/bottomRight`는 각각 left/right 세로 알약으로, 세로 위치는 화면 아래쪽 40pt 위.
7. **말풍선(say)·알림 카드:** 알약 옆(화면 안쪽)으로 나온다 — 지금 위치 계산이 펫 창 기준이라 그대로 두고 확인.

## 요구사항
- R1. 가장자리에 놓으면 알약(세로/가로)으로, 끌어내면 보통 펫.
- R2. 호버하면 펼쳐져 시계·작업 한 줄, 떠나면 접힘.
- R3. 구슬 점 색이 작업 상태를 따른다. 새 알림이면 테두리 색 + 잠깐 펼침.
- R4. 알약 안 곰은 고개·눈만 움직이고, 움직임 끄기면 가만히.

## 설계
- `Geometry`: `islandFrame(dock:, expanded:, origin:, in:) -> CGRect`(순수) 추가, 붙은 상태의 `frame`은 이것으로.
- `PetView`: `island` 상태(방향·펼침·점 색·시계 글·작업 글·테두리 색)와 그리기(층). 곰 칸 위치.
- `Pet3DView`: `compact` 모드(몸 움직임 0, 카메라 가까이).
- `PetController`: `place`에서 붙으면 알약 크기, 호버 펼침, 구슬 점 갱신(`updateBeads`에서 함께), 시계 틱 때 글 갱신, 끌기 시작 때 보통 크기로.

## 검증
- 자체 검사(`islandFrame`): 오른쪽 접힘이 화면 끝 4pt 안쪽·세로 위치 화면 안, 펼침이 같은 끝에 붙은 채 커짐, 아래 가로, 구석 → 옆 세로, 작은 화면에서도 안에 들어감.
- `--render-bear` 옆에 알약 그림 확인용 출력 추가는 하지 않음(창 그리기라 화면 확인).
- 모습·펼침 움직임·끌어내기는 사용자 확인.
