# F2 폴더 서랍
- 작성: 2026-10-22 (소급 작성) · 요청자: 사용자 · 상태: 구현됨
- 성공 기준 표시: ✅ 확인함 · ❓ 화면에서 미확인

## 문제
자주 가는 폴더를 보려면 Finder를 열어 찾아가야 한다.

## 원하는 결과
- 탐색할 폴더를 저장해 두고, 키를 누른 채 펫에 커서를 올리면 서랍이 열려 폴더 내용을 바로 본다.
- Finder 칼럼 보기처럼 한 번 클릭으로 다음 칸이 펼쳐지고, 루트부터 깊이가 늘어난다.
- 파일을 클릭하면 미리보기, 폴더·파일이 구분된다.
- 하단에 현재 경로가 보이고 경로를 누르면 그곳으로 간다.
- 창 크기 조절·드래그 이동, 바깥 클릭으로 닫힘.
- 오른쪽 클릭 등 맥의 기본 상호작용.

## 범위
- 포함: 저장 폴더 목록(추가·순서·빼기), 칼럼 탐색, 미리보기, Quick Look, 끌어내기·끌어 넣기, 오른쪽 클릭 메뉴(열기·다음으로 열기·빠른 보기·Finder에서 보기·이름 변경·복제·휴지통·복사·경로 복사·새 폴더·붙여넣기), Finder 단축키(⌘⌫ ⌘C ⌘V ⌘D ⌘O Return), 크기 기억
- 제외: 영구 삭제

## 제약
- 더블클릭으로 Finder 앱을 띄우지 않는다. 열기 키는 설정에서 바꾼다(⌥·⌃·⌘·⇧).

## 성공 기준
- ✅ 빌드 통과
- ❓ 칼럼 확장·경로 이동·크기 조절·바깥 클릭 닫힘·오른쪽 클릭 메뉴의 실제 동작

## 열린 질문
- 없음
