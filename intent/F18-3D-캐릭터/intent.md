# F18 3D 메인 캐릭터와 모션
- 작성: 2026-10-29 · 요청자: 사용자 · 상태: 승인됨(2026-10-29)
- (추정) 표시는 사용자가 아직 확인하지 않은 부분
- 기본 그림: base.png (크림색 둥근 곰, 분홍 귀, 검은 눈·코, 짧은 팔, 꼬리)

## 문제
- 지금 펫은 2D 그림 한 장씩을 바꿔 보여 줘서 움직임이 딱딱하다. 서비스의 얼굴이 될 메인 캐릭터가 없다.

## 원하는 결과
- base.png 곰이 Tasky의 메인 펫이 되고, 3D로 자연스럽게 움직인다.
- 3D 모델은 사용자가 Tripo3D로 만들어 준다(뼈대 포함). 앱에 넣는 일과 모션은 코드로 만든다.
- 모션(추정, 지금 상황표 기준):
  - 평소: 숨쉬기, 눈 깜빡임, 커서 쪽으로 고개 돌리기, 가끔 두리번
  - 반응: 쓰다듬기 좋아함, 찌르기 움찔·삐침, 잡으면 대롱대롱, 착지 찌그러짐, 던지면 데굴데굴
  - 작업 알림: 일하는 중 까딱, 내 차례 손 흔들기(구슬 쪽 보며), 끝남 폴짝, 실패 시무룩
  - 쉼: 졸기, 명상

## 범위
- 포함: 3D 모델 불러오기, 위 모션, 기존 2D 그림 캐릭터와 고르기
- 제외(추정): 옷 갈아입히기, 다른 3D 캐릭터 추가

## 제약
- Apple 기본 프레임워크만(SceneKit). 새 라이브러리 없음. (추정)
- 포커스를 뺏지 않는 투명 펫 창은 그대로.
- CPU·메모리: 가만히 있을 때 지금 2D와 큰 차이 없게(개발자 탭으로 잼). (추정: 기준은 spec에서)
- 동작 줄이기 설정이면 큰 움직임을 줄인다.

## 성공 기준 (추정)
- [ ] 모델 파일을 넣으면 펫이 3D 곰으로 보인다
- [ ] 상황마다 정해진 모션이 끊김 없이 이어진다
- [ ] 커서를 따라 고개를 돌린다
- [ ] 가만히 있을 때 CPU가 2D 때와 비슷하다
