# F18 3D 메인 캐릭터 — spec
- 작성: 2026-10-29 · 근거: intent.md(승인됨) · 상태: 승인됨(2026-10-29)

## 지금 상태
- `PetView`(2D): `Character` 그림 한 장을 상황(`Situation`: idle·drag·happy·sleep·walk…)마다 바꿔 보여 줌, 숨쉬기·흔들기는 층 애니메이션. 펫 창은 투명 `FloatingPanel` 120×120(크기 설정 있음).
- 컨트롤러는 `petView.react(_:)`, `base`, `lean(_:)`, `waveHand()` 등으로 펫을 부린다.

## 우려 사항
1. **그리는 곳 — 추천: `SCNView`를 펫 창에 넣은 `Pet3DView`, `PetView`와 같은 바깥 모양(react·base·lean…)을 갖게.** 컨트롤러는 프로토콜 하나(`PetBody`)로 둘 다 부른다. 배경 투명(`backgroundColor = .clear`, 창 불투명 아님), 그림자 없음.
2. **임시 곰(모델 오기 전) — 추천: 코드로 만든 도형 곰.** 몸 = 위아래로 조금 긴 공, 귀 2(공 + 분홍 안쪽 원판), 눈 2(검은 반짝 공), 주둥이(납작 공) + 코, 팔 2(캡슐), 꼬리(작은 공). 색은 base.png 크림(#F3EAD8)·분홍(#F2B8B8). 노드 이름을 Tripo 모델 뼈 이름과 맞출 표(`root/body/head/ear_L…`)로 두면 모델이 와도 모션 코드는 그대로.
3. **모션 엔진 — 추천: 직접 만든 작은 스프링 계층.**
   - 매 화면 갱신마다(`SCNSceneRendererDelegate`) 각 관절의 목표 값(회전·크기)을 상황 모션이 정하고, 실제 값은 스프링(강도·감쇠)으로 따라간다 → 찌그러짐 되튐, 귀·꼬리 한 박자 늦게.
   - 상황 모션 = 시간 → 목표 값 함수(숨쉬기 사인, 걷기 뒤뚱, 대롱대롱 = 잡은 점 기준 진자). 바뀔 때 0.25초 섞기.
   - 고개는 커서 방향(펫 기준 각도, 최대 ±25°)을 목표로.
   - 표정: 블렌드 셰이프가 있으면 `SCNMorpher` 가중치, 임시 곰은 눈 노드 y 크기(감기 0.1·놀람 1.3).
4. **성능 — 추천:** 가만히 있을 때 30fps로 낮추고(`preferredFramesPerSecond`), 펫이 안 보이거나(빼꼼 숨김·다른 Space) 잠들면 멈춤. 개발자 탭으로 CPU를 2D와 비교해 spec 기준: 가만히 있을 때 CPU 3% 이하(추정, 재고 조정).
5. **모델 받기 — 추천:** `~/Library/Application Support/Tasky/Characters/<이름>/model.usdz`(또는 .glb → usdz 변환은 사용자 쪽에서 Reality Converter). glb는 SceneKit이 바로 못 읽는다. 파일이 있으면 캐릭터 목록에 '3D'로 뜬다.
6. **2D와 고르기:** 설정 → 펫 → 캐릭터에 '곰 3D(기본)'을 맨 위에. 기존 2D 그림 캐릭터는 그대로.
7. **동작 줄이기:** 진자·데굴데굴·두리번을 끄고 숨쉬기·깜빡임만.

## 요구사항
- R1. 기본 펫이 3D 곰(임시 도형, 모델 파일이 있으면 그 모델).
- R2. 위 표의 모션이 상황에 맞게 섞여 이어진다.
- R3. 2D 캐릭터를 고를 수 있다. 컨트롤러 코드는 둘 다 같은 방식으로 부른다.
- R4. 가만히 있을 때 CPU 기준(4번), 안 보이면 멈춤.

## 설계
- `Pet3D.swift`(새로): `PetBody` 프로토콜(지금 `PetView`가 쓰이는 메서드들), `Pet3DView`(SCNView), `ProceduralBear`(도형 곰), `Spring`·`MotionClip`(순수, 자체 검사), `BearRig`(노드 이름 표).
- `PetView`: `PetBody` 따르기만. `PetController`: `petView` 타입을 `PetBody`로.
- `Character`: 3D 항목 추가.

## 검증
- 자체 검사: 스프링이 목표에 수렴하고 넘침이 감쇠 설정대로, 0.25초 섞기 중간값, 고개 각도 제한, 동작 줄이기면 진자 끔.
- CPU: `--debug` 개발자 탭 CSV로 2D/3D 비교(가만히 1분).
- 모습·자연스러움은 사용자 확인.
