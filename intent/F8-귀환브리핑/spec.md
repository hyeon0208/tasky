# F8 귀환 브리핑 — spec
- 작성: 2026-10-22 · 근거: intent.md(승인됨 2026-10-22) · 상태: 승인됨

## 우려 사항 (모두 결정됨)
1. ✅ **"손을 흔든다"의 표현 — 결정:** 펫 몸 옆에 간단한 손 모양을 그려 몇 번 흔든다. 디자인 에셋을 받으면 그것으로 교체한다.
2. ✅ **'그 사이'에 넣을 작업의 기준 — 결정:** 실패·끝남은 자리를 비운 동안 바뀐 것만 넣는다. 승인 대기는 떠나기 전부터 기다리던 것도 포함해, 돌아온 시점에 아직 기다리는 작업을 모두 넣는다.
3. ✅ **여러 펫일 때 — 결정:** 펫마다 자기 브리핑을 가진다. 작업은 그 펫의 '작업 알림 받기' 설정(전부·Claude만·Codex만)에 맞는 것만, 변환 결과는 그 펫에서 변환한 것만 넣는다. 항목이 생긴 펫마다 손을 흔들고 자기 첫 칸에 "그 사이 N건"을 보이며, 닫으면 그 펫의 브리핑만 비워진다.
4. ✅ **잠금 감지 방법 — 결정:** 화면 잠금·해제는 비공식 `com.apple.screenIsLocked` / `com.apple.screenIsUnlocked` 알림, 잠자기·깨어나기는 공식 `NSWorkspace.willSleepNotification` / `didWakeNotification`. 비공식 알림이 앞으로 동작하지 않으면 화면 잠금 후 브리핑만 빠지고 다른 기능은 그대로다. 입력 감시는 쓰지 않는다.

## 요구사항
- R1. 자리 비움 시작: 화면 잠금 또는 잠자기 시작 시각을 기록한다. 싱잉볼 쉼 시작도 같은 방식으로 기록한다.
- R2. 돌아옴: 잠금 해제·깨어나기·쉼 종료 때, 기록한 시각 이후 생긴 항목을 모은다. 비어 있으면 아무것도 하지 않는다(시간 길이와 상관없음).
- R3. 펫마다(우려 3) 항목이 있으면 그 펫이 손을 흔들고(우려 1), 그 펫의 원형 메뉴 첫 칸이 "그 사이 N건"이 된다.
- R4. 첫 칸을 누르면 펫 옆에 브리핑 창. 순서: 승인 대기 → 실패 → 끝난 작업(마지막 응답 앞부분) → 변환 결과(누르면 Finder에서 보기).
- R5. 브리핑을 닫으면 그 펫의 브리핑과 "그 사이 N건"이 비워진다. 작업 알림 목록은 그대로.
- R6. 쉼(F6)이 끝날 때 작업 알림 목록을 여는 임시 방식을 없애고, R2~R3으로 대신한다.
- R7. 자리를 비운 동안 다시 비우면(예: 잠금 중 잠자기) 처음 시각을 유지하고, 이미 브리핑이 쌓여 있으면 새 항목을 더한다.

## 설계

### 항목 모으기 (새 파일 `Briefing.swift`)
- `Briefing`(순수 로직): `awaySince: Date?`, `items: [Item]`.
  - `leave(at:)`: 비어 있으면 시각 기록(R7).
  - `collect(sessions:conversions:now:)`: 돌아온 시점에 승인 대기인 세션 전부(우려 2), `awaySince` 이후 `updated`된 실패·끝남 세션, 그 이후 끝난 변환 결과를 모아 순서대로 정렬해 `items`에 더한다(같은 세션은 한 번, 최신 상태로).
  - `clear()`: 닫을 때 비움.
- 펫마다 `Briefing`을 하나씩 가진다. `collect`에 그 펫이 받는 도구의 세션만 넘긴다(`accepts(tool)`).
- 변환 결과에 끝난 시각이 필요하므로, 각 펫이 변환이 끝날 때 `(시각, 결과 파일들)`을 기록한다(지금은 마지막 결과만 들고 있음).
- 감지(잠금·잠자기·쉼)는 `App`이 한 번 받아 모든 펫에 `leave`/`collect`를 전한다.

### 감지 (`App`)
- 잠금: `DistributedNotificationCenter`의 `com.apple.screenIsLocked` → `leave`, `com.apple.screenIsUnlocked` → `collect`.
- 잠자기: `NSWorkspace.shared.notificationCenter`의 `willSleep` → `leave`, `didWake` → `collect`.
- 쉼: `openBowl` → `leave`, `endRest` → `collect`(F6의 `listPet()?.openAgentList()` 임시 코드와 `shortcut:` 주석 삭제).

### 화면
- 첫 칸 우선순위: 그 사이 N건 > 기다리는 작업 > 끝난 작업 > 변환 결과 > 쓰다듬기.
- 브리핑 창: 작업 알림 목록과 같은 모양의 패널(약 420×380), 묶음 제목(승인 대기·실패·끝남·변환)과 항목, 항목 버튼(터미널로 가기·Finder에서 보기), '닫기'. 바깥 클릭·Esc로도 닫힘(닫힘 = R5).
- 펫 손 흔들기: `PetView`에 손 그림(작은 둥근 손)을 더하고, 약 1.5초 동안 좌우로 흔든 뒤 사라진다.

## 검증 방법
- 자체 검사: 도구 설정에 맞지 않는 세션 제외, 비움 시각 이전의 실패·끝남 제외·이후 포함, 이전부터 기다리던 승인 대기 포함, 순서(승인 대기→실패→끝남→변환), 같은 세션 중복 없음, 겹친 자리 비움(R7), 비면 아무것도 안 함, 닫으면 비움.
- 실행 확인: 화면 잠금·해제, 잠자기·깨어나기, 싱잉볼 쉼 종료에서 실제 표시는 사용자 확인(제가 화면을 잠그거나 볼 수 없음).
