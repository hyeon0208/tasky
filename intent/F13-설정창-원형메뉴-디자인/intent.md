## 문제
- 설정 창이 한 장에 모든 구역을 늘어놓아 길고, 무엇이 어디 있는지 찾기 어렵다.
- 키보드 설정을 바꾼 뒤 확인하려면 다른 앱에 가서 쳐 봐야 한다.
- 원형 메뉴가 "조잡"하다(이름표가 다 떠 있고, 버튼 모양이 평평함).

## 원하는 결과
- 설정 창: 위쪽 아이콘 탭(일반·깍지·작업 알림·키보드·쉼·정보, --debug면 '개발자' 추가 → F17). 탭마다 한 화면.
- 키보드 탭 맨 위 '바로 테스트' 칸: 입력 소스(가/A)·대문자 고정(⇪) 표시, 설정을 바꾸면 그 칸에서 바로 한영 전환·키 꾹 누르기를 해 볼 수 있다.
- 원형 메뉴: 펫 위쪽 반원(약 200°)에 같은 크기 원형 유리 버튼, 반사광·빛 테두리·그림자로 볼록한 유리알. 이름표는 커서를 올린 버튼 하나만 펫 아래에. 펼칠 때 0.9배→1배 0.18~0.22초, 25ms 간격, 누르면 0.95배. 기다리는 작업 수는 숫자 배지.
- macOS 26 이상은 시스템 유리, 그 아래는 같은 층을 직접 그린다. 동작 줄이기·투명도 줄이기 설정을 따른다.

## 범위
- 포함: 설정 창 구조와 모양, 키보드 바로 테스트, 원형 메뉴 모양·움직임
- 제외: 설정 항목 자체의 추가(각 기능 문서에서), 펫 캐릭터 그림

## 제약
- 바로 테스트 칸은 설정 창 안의 일반 입력 칸이다(키를 따로 기록·전송하지 않음).
- 설정 창은 지금처럼 펫을 따라다닌다. 탭 위치는 다시 열 때 기억한다. (추정)

## 성공 기준
- [ ] 탭을 누르면 해당 설정만 보이고, 창을 닫았다 열면 마지막 탭이 열린다
- [ ] 키보드 탭에서 전환 키를 바꾸면 테스트 칸에서 바로 새 키로 한영이 바뀌고, 표시(가/A·⇪)가 따라 바뀐다
- [ ] 원형 메뉴가 위쪽 반원에 펼쳐지고, 이름표는 올린 버튼 하나만 보인다
- [ ] 동작 줄이기를 켜면 펼침 움직임 없이 나타난다
