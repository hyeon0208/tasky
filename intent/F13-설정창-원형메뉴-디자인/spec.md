# F13 설정 창·원형 메뉴 디자인 — spec

## 지금 상태 (코드로 확인)
- 설정: `PetController.openSettings()`가 한 장짜리 스택(구역: 깍지 모양·작업 알림·폴더 서랍·키보드·시작)을 만든다. 펫마다 값(크기·캐릭터·돌아다니기·받을 알림)과 공통 값이 섞여 있다.
- 원형 메뉴: `RingView` + `GlassButton`(지름 48, 시스템 유리 또는 뒤 흐림 + 빛 테두리) + 버튼마다 `GlassLabel` 이름표. 자리 계산은 `Geometry.slotCenters`: 떠 있을 때 360° 원(8개씩 겹), 가장자리에 붙었을 때 화면 안쪽 부채꼴.

## 우려 사항
1. **위쪽 반원만 쓸지 — 추천: 떠 있을 때만 위쪽 200°, 가장자리에 붙었을 때는 지금처럼 화면 안쪽 부채꼴.** 펫이 화면 왼쪽에 빼꼼 중이면 위쪽 반원은 반이 화면 밖이다.
   - 떠 있을 때 버튼이 7개를 넘으면 바깥 겹(반지름 +50)으로 넘긴다. 지금 버튼은 최대 7개(첫 칸 + 6).
   - 펫이 화면 위쪽 끝(위로 버튼 반지름만큼 공간 없음)이면 아래쪽 반원으로 뒤집는다.
2. **유리 모양을 어디서 만들지 — 추천: 지금 `GlassButton` 층에 반사광 층(위 왼쪽 타원 그라데이션)과 안쪽 그림자 두 개(위 밝게, 아래 어둡게)를 더한다.** 시스템 유리(macOS 26+)도 반사광은 우리가 얹는다. 시안의 '뒤 배경 굴절'은 macOS 26 이상에서만 시스템 유리가 해 주고, 그 아래는 흐림까지만 된다(굴절은 직접 그릴 수 없음).
3. **이름표 — 추천: 버튼마다 붙은 이름표를 없애고 링 아래(펫 몸 아래 8pt)에 하나만 두고, 올린 버튼의 이름으로 0.12초 바뀜.** 키보드 포커스로 버튼을 옮겨도 같은 이름표.
4. **설정 탭 구조 — 추천: `NSTabViewController`(스타일 `.toolbar`)가 아니라, 직접 만든 아이콘 탭 줄 + 탭마다 스택 뷰 교체.** 지금 설정은 비활성 패널(FloatingPanel)이라 일반 창 도구 막대를 쓸 수 없다. 탭 줄은 시안처럼 아이콘(SF Symbols) + 이름.
5. **탭과 항목 배치 (펫마다 값은 '깍지' 탭으로 모은다)**
   - 일반: 컴퓨터를 켤 때 실행, 메뉴 투명도, 폴더 서랍 열기 키
   - 깍지(이 펫): 크기, 캐릭터, 돌아다니기, 이 깍지가 받을 알림
   - 작업 알림: 알림음, Claude Code·Codex 연결
   - 키보드: 바로 테스트, 한영 전환(켜기·키·권한), 키 반복(두 슬라이더·처음 값으로)
   - 쉼: 지금은 소리 크기 하나 (추정: 비어 보이면 탭을 빼고 일반에 넣음)
   - 정보: 버전, 권한 상태(입력 모니터링·손쉬운 사용) 한눈에
   - 개발자: F17에서 (`--debug`일 때만)
6. **바로 테스트 칸 — 추천: 설정 창이 키를 받을 수 있는 패널(`keyable`)이라 일반 `NSTextField`면 된다.** 입력 소스 표시(가/A)는 `kTISNotifySelectedKeyboardInputSourceChanged` 알림으로, 대문자 고정(⇪)은 `flagsChanged` 로컬 감시로 갱신. 칸에 쓴 글자는 저장하지 않는다.
   - 주의: 테스트 칸에 포커스가 있으면 설정 창이 키 입력을 가져간다. 칸을 누를 때만 그렇다(지금 패널도 같음).
7. **창 크기 — 추천: 너비 520 고정, 높이는 탭 내용에 맞춰 바뀜(0.18초).** 펫 따라다니기(2번 수정)는 그대로.

## 설계
- `SettingsView.swift`(새로): 탭 줄 + 내용 교체. `PetController.openSettings()`의 항목 만들기 코드는 탭별 함수로 나눠 옮긴다(동작은 그대로). 마지막 탭은 UserDefaults `settingsTab`.
- `RingView.swift`: `GlassButton`에 반사광·안쪽 그림자 층, 지름 50, 누름 0.95배, 올림 1.08배·2pt 위로. 이름표 하나. 펼침 0.9→1배 + 투명→불투명 0.22초, 25ms 간격(동작 줄이기면 투명도만). 배지(기다리는 작업 수)는 주황 공.
- `Geometry.slotCenters`: 떠 있을 때 위쪽 200° 부채꼴(+ 위 공간 없으면 아래로 뒤집기). 자체 검사 추가.

## 검증 방법
- 자체 검사: 떠 있을 때 버튼이 모두 펫 중심보다 위(또는 뒤집기 시 아래), 7개 넘으면 바깥 겹, 버튼끼리 안 겹침(중심 거리 ≥ 지름).
- 빌드. 모양·움직임·테스트 칸은 사용자 화면 확인.
