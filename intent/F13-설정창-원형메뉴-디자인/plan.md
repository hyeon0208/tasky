## 작업 순서와 검사

### 1. 링 자리 (`Geometry`)
- `slotCenters(count:dock:center:size:roomAbove:)`: `.free`면 시작 190°→끝 -10°로 고르게. 한 겹 최대 7개, 넘으면 반지름 +50 겹. `roomAbove == false`면 각도 부호를 뒤집어 아래로.
- 가장자리에 붙었을 때는 지금 계산 그대로.
- **검사:** 6개 → 모두 중심보다 위(y > c.y - 1), 이웃 중심 거리 ≥ 50; 9개 → 두 겹; roomAbove=false → 모두 아래; 붙었을 때 결과는 바뀌기 전과 같음.

### 2. 유리 버튼·이름표 (`RingView`)
- 반사광: 버튼 위 왼쪽 타원 `CAGradientLayer`(흰 0.85 → 0, -18° 회전). 안쪽 그림자: 위 1.5pt 밝은 테두리, 아래 어두운 안쪽 그림자(`CAShapeLayer` 고리 + 흐림). 바깥 그림자 0 10 22 / 0.45.
- 시스템 유리(macOS 26+)여도 반사광은 얹는다. 투명도 줄이기면 반사광·흐림 없이 불투명 배경.
- 이름표 하나: 링 아래 `GlassLabel`, 버튼에 마우스가 들어오거나 키보드 포커스가 오면 이름 바꾸고 0.12초 나타남, 나가면 숨김.
- 배지: 슬롯에 `badge: Int?`, 주황 공(18pt) 오른쪽 위.
- 움직임: 펼침은 각 버튼이 펫 쪽 40% 지점·0.9배·투명에서 0.22초 ease-out(0.23,1,0.32,1), 25ms 간격. 동작 줄이기면 투명도만.
- **검사:** 빌드. 모양은 사용자 확인.

### 3. 설정 탭 (`SettingsView` + `PetController`)
- 탭: 일반(gearshape)·깍지(leaf)·작업 알림(bell)·키보드(keyboard)·쉼(bell.and.waves... 없으면 cup.and.saucer)·정보(info.circle). F17이 '개발자'를 덧붙일 자리(`extraTabs`)만 열어 둔다.
- 항목 옮기기(동작 그대로):
  - 일반: 컴퓨터를 켤 때 실행, 메뉴 투명도, 폴더 서랍 열기 키
  - 깍지: 크기, 캐릭터, 이 깍지가 받을 알림
  - 작업 알림: 알림음, Claude Code·Codex 연결
  - 키보드: 바로 테스트 + 기존 키보드 항목
  - 쉼: 소리 크기(새 슬라이더, `BowlSynth.volume`에 저장값 적용) — 하나뿐이라 일반으로 합침 (spec 우려 5의 추정대로)
  - 정보: 버전, 권한 상태(입력 모니터링·손쉬운 사용 각각 허용/아님)
- 탭을 바꾸면 패널 높이를 내용에 맞춰 0.18초로 바꾼다(위쪽 고정).
- **검사:** 빌드, 자체 검사 전체.

### 4. 바로 테스트 칸
- `NSTextField` + 왼쪽 44pt 표시. 입력 소스: `DistributedNotificationCenter`의 `kTISNotifySelectedKeyboardInputSourceChanged`로 `InputSources` 언어 확인 → 가/A. 대문자 고정: `NSEvent.addLocalMonitorForEvents(.flagsChanged)`로 ⇪ 붙이기. 설정 창을 닫으면 감시 해제.
- 한영 전환 키·반복 값을 바꾼 뒤 칸에서 바로 확인(별도 동작 없음, 이미 즉시 적용됨).
- **검사:** 빌드. 실제 표시는 사용자 확인.

## 구현 결과와 plan과 다른 점 (2026-10-28)
- 빌드·자체 검사 통과(떠 있을 때 위쪽 반원, 7개 넘으면 두 겹, 위 공간 없으면 아래로, 칸 사이 50pt 이상).
- 독립 검토 반영: 탭을 바꿀 때 창이 커지는 동안 탭 줄이 잘리지 않게 위에 고정, 커진 창이 화면 아래로 넘치지 않게, 펫을 숨기면 설정도 닫고 감시 해제, 쉬는 중에 소리 크기를 바꾸면 바로 적용.
- 다른 점:
  - 메뉴 투명도는 모든 펫 공통이라 '일반' 탭으로.
  - 첫 칸(상황 칸)이 위 가운데가 아니라 반원의 왼쪽 끝.
  - 누를 때 0.95배는 넣지 않음(누르면 링이 바로 닫혀 보이지 않음).
  - 칸 사이를 키보드 포커스로 옮기는 기능이 원래 없어 이름표는 마우스만 따른다(숫자 키로 실행은 그대로).
  - F17 '개발자' 탭 자리는 F17에서 만든다.
  - 가장자리에 붙었을 때·아래로 뒤집혔을 때 이름표는 예전처럼 칸 옆에 떠 이웃 칸을 살짝 가릴 수 있다(검토 지적, 화면 확인 후 결정).
- 확인 못 함: 유리 모양·반사광, 펼침 움직임, 탭 높이 바뀜, 테스트 칸 표시.
