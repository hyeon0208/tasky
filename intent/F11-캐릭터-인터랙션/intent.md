# F11 캐릭터 디자인·여러 캐릭터·인터랙션

- 참고 이미지: reference/ (ref-1·2는 전체 시트, chosen-1~5는 고른 9마리)

## 문제
지금 펫은 코드로 그린 임시 콩깍지 하나뿐이라 귀여움·애착이 약하고, 동작(쓰다듬기, 빼꼼, 받기, 알림 반응, 싱잉볼, 손 흔들기)이 단순한 도형 변화에 그친다.

## 원하는 결과
- 참고 이미지처럼 손으로 그린 크레용 질감, 굵은 갈색 외곽선, 둥글고 통통한 몸, 작은 점 눈과 무표정·졸린 표정의 캐릭터.
- 캐릭터 9마리 중에서 펫마다 고른다: 병아리, 카피바라, 회색 햄스터, 물범, 파란 상어, 시바, 흑백 고양이, 회색 상어, 갈색 새(볼터치). 이름은 사용자가 정한다.
- 앱의 상황마다 캐릭터가 반응하고(웃기, 손 들기, 떨기, 뛰기, 졸기 등), 손으로 만지면 풍부하게 반응한다.
- 에셋은 사용자가 따로 만든다. 필요한 에셋 목록은 ASSETS.md.

## 범위
- 포함: 에셋 방식은 표정 그림(정지 PNG) + 코드 움직임(ASSETS.md), 캐릭터 9종 교체(2D), 펫마다 캐릭터 고르기, 동작(표정 그림 + 코드 움직임), 효과 표시(zz·…·!·하트 등), 추천 인터랙션(ASSETS.md 6절)
- 제외: 3D(추후), 편지(F7 보류), 사용자 색 지정(캐릭터 고유 색 사용, 기존 색 설정은 숨김)

## 제약
- 참고 이미지는 분위기 참고용이다. 앱에 넣는 에셋은 사용자가 직접 만들었거나 사용 권리가 확인된 것만.
- 포커스를 뺏지 않고, 키보드·마우스 사용량을 보지 않는다(기존 원칙). 커서 위치는 펫 창 근처에서만 읽는다.
- 화면을 돌아다니는 동작처럼 작업을 방해할 수 있는 것은 설정으로 끌 수 있다.
- 에셋이 오기 전에는 지금 2D 그림으로 같은 동작을 임시로 보여 주고, 에셋은 파일만 넣으면 바뀌게 한다.
