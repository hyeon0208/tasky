## 설계

### 캐릭터 불러오기 (새 파일 `Character.swift`)
- `Character`: 폴더 이름, 표정 이름 → `NSImage?`. 우려 1의 폴더에서 처음 쓸 때 읽어 캐시.
- 파일 이름은 영어·한국어 둘 다 읽는다: 기본=idle, 눈감음=blink, 졸음=sleep, 행복=happy, 놀람=surprised, 슬픔=sad, 인사=handup, 입벌림=mouthopen, 눌림=squish, 대롱=dangle, 걷기=walk1(walk2 없으면 반전 흔들기), 명상=bowl, 화남=grumpy, 점프=jump(새 표정: 작업 끝남 통통·던지기, 없으면 happy).
- 원본 폴더(`원본/`)는 읽지 않는다. 체크무늬가 그려진 가짜 투명 그림은 '배경 지우기'로 지운 뒤 넣는다.
- 표정 대신 규칙: `dangle`/`walk1`/`walk2`/`bowl`/`grumpy`가 없으면 각각 idle/idle/idle/sleep/sad, 그 밖은 idle.
- 효과 그림: `Effects/` 폴더, 없으면 SF Symbols(`zzz`, `ellipsis.bubble`, `exclamationmark`, `heart.fill` 등).

### 그리기와 움직임 (`PetView` 교체)
- 레이어 3장: 캐릭터 그림(`contents`에 표정 이미지), 효과 그림(머리 위), 기존 손 레이어 제거(handup 표정으로 대체).
- 그림이 없는 캐릭터·표정은 지금의 콩깍지 그림을 그대로 그린다(우려 4).
- 움직임은 모두 Core Animation 키프레임(`transform`·`position`·`opacity`)으로, 동작 줄이기 설정이면 크기·위치 움직임 없이 표정만 바뀐다.

### 상태 (`PetController`)
- `mood`(표정)와 `motion`(움직임)을 정하는 작은 함수 하나: 상황 이벤트 → (표정, 움직임, 효과, 지속 시간). 동작 표(ASSETS.md 5절)를 그대로 옮긴 표 형태로 둔다.
- 졸기 타이머(5분 무상호작용), 찌르기 횟수(3초 안 5번), 깜빡임 타이머(3~8초).
- 던지기: 놓을 때 마지막 끌기 속도로 창을 미끄러뜨리고 감속, 화면 안에서 멈춤.
- 돌아다니기: 켜져 있고 빼꼼·서랍·링·브리핑이 모두 닫혀 있을 때만, 가끔 화면 아래를 몇 초 걷다 멈춘다.
- 펫끼리: 끌기를 놓았을 때 다른 펫과 가까우면(약 200pt 안) 서로 바라봄 + 하트.
