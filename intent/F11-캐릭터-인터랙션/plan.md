## 작업 순서와 각 단계의 검사

### 1. `Character` — 그림 불러오기 (순수에 가깝게)
- `Character.available()`: `Characters/` 아래에서 그림이 하나라도 있는 폴더만(지금은 chick). `원본/` 하위 폴더는 읽지 않는다.
- `image(for pose:)`: 영어 이름 → 한국어 이름 순으로 찾고, 없으면 대신 규칙(spec). 처음 쓸 때 읽어 캐시.
- **기본(idle)이 아직 없어서:** idle이 없으면 점프 → 행복 순으로 대신한다(병아리 점프 그림이 무표정 서 있는 모습이라 기본에 가장 가까움). 기본.png를 넣으면 자동으로 바뀐다.
- 효과: `Effects/<이름>.png`, 없으면 SF Symbols.
- **검사:** 자체 검사에 임시 폴더(`KONGPOD_HOME`)로 ① 한국어 이름 찾기 ② 대신 규칙(bowl 없음 → sleep, sleep 없음 → idle) ③ idle 없음 → 점프 ④ 그림 없는 폴더는 목록 제외 ⑤ `원본/` 무시.

### 2. 반응 표 (순수)
- `enum Situation`(대기, 졸기, 클릭, 쓰다듬기, 삐침, 끌기, 착지, 던지기, 파일 다가옴, 변환 중, 변환 끝, 작업 끝남, 승인 대기, 실패, 브리핑, 싱잉볼, 걷기, 펫끼리) → `Reaction(pose, motion, effect, seconds)`. ASSETS.md 5절을 그대로 옮긴다.
- 찌르기 판정 `PokeCounter`(3초 안 5번), 졸기 판정(마지막 상호작용 후 5분).
- **검사:** 표 전체가 빠짐없이 정의됨(모든 `Situation`), 찌르기 4번 → 아님·5번 → 삐침·3초 지나면 초기화, 졸기 경계값.

### 3. 그리기와 움직임 (`PetView`)
- 캐릭터가 있으면 창을 정사각(120×120 × 크기 배율)으로, 그림 층(`CALayer.contents`)에 표정을 넣는다. 그림 바닥선(아래 12%)을 창 아래에 맞춘다.
- 효과 층: 머리 위에 잠깐(zz는 졸 때 계속).
- 움직임은 Core Animation 키프레임. 동작 줄이기면 표정만 바뀐다.
- 기존 손 그림(`waveHand`)·몸 그릇(`holdingBowl`)은 캐릭터가 있을 때 handup·bowl 그림으로 대신하고, 콩깍지일 때는 그대로 둔다.
- 작업 상태 콩알은 캐릭터일 때 숨기고 표정·효과로 보여 준다 (추정).
- **검사:** 빌드. 실제 모습은 사용자 확인.

### 4. 상황 연결 (`PetController`)
- 기존 신호에 반응 연결: 링 열기(클릭), 쓰다듬기, 끌기 시작·놓기, 파일 다가옴·변환, 작업 상태 변화, 브리핑 손 흔들기, 싱잉볼 쉼.
- 깜빡임 3~8초, 졸기 5분, 찌르기 판정.
- 던지기: 놓기 직전 끌기 속도로 미끄러지며 감속, 화면 안에서 멈춘 뒤 빼꼼 판정은 기존대로.
- 펫끼리: 놓았을 때 다른 펫과 200pt 안이면 서로 바라봄 + 하트.
- 돌아다니기(설정, 기본 꺼짐): 빼꼼·서랍·링·브리핑·싱잉볼이 모두 닫혀 있을 때만, 가끔 화면 아래쪽으로 몇 초 걷다 멈춤.
- 설정 '이 깍지': 색상표 대신 캐릭터 고르기(콩깍지 + 그림 있는 캐릭터), 돌아다니기 켜기. 펫마다 저장.
- **검사:** 자체 검사에 던지기 감속이 화면 안에서 멈춤(순수 함수로 분리), 펫끼리 거리 판정. 나머지는 빌드.

### 5. 마무리
- 자체 검사 전체 통과, 빌드 경고 없음.

## 구현 결과와 plan과 다른 점 (2026-10-27)
- 자체 검사 통과(그림 찾기·한국어/NFD 이름·대신 규칙·원본 무시, 반응 표, 찌르기·졸기, 던지기, 펫끼리 거리, 정사각 빼꼼). 화면·소리는 확인 못 함.
- 독립 검토 반영: 쉼 중 끌기·파일·변환 뒤 쉼 자세로 복귀, 던지기·걷기 중 잡으면 그 자리에서 멈춤, 걷다 멈춰도 위치 저장, 콩깍지 모드는 삐침·던지기·펫끼리 반응 없음(기존 그대로), 캐릭터를 바꿀 때 숨쉬기 정리, 그림 바닥선을 창 아래에 맞춤, 싱잉볼을 칠 때 음표 효과.
- 다른 점:
  - 기본 캐릭터: 고른 적 없는 펫은 그림이 있는 첫 캐릭터(지금은 병아리)로 시작 (추정, 사용자 확인 필요).
  - 돌아다니기: 화면 아래가 아니라 지금 높이에서 옆으로 걷는다.
  - 펫끼리: 정면 그림이라 서로 바라보는 뒤집기는 하지 않고 하트·통 튀기만.
  - 연속 표정 일부 생략: 파일 다가옴은 놀람 없이 입벌림, 변환 중은 입벌림 + 우물우물, 쓰다듬기는 눈감음 없이 행복.
  - 매달림(진자)은 발바닥 축으로 흔든다(머리 축 아님).
  - 빼꼼·원형 메뉴 계산은 그대로 쓰고 정사각 창 검사 1개만 더했다.
