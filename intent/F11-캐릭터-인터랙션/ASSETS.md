# F11 에셋 요청서
- 작성: 2026-10-23 · 상태: 확정
- 방식(추천안): **캐릭터마다 표정 그림(정지 PNG) 몇 장 + 움직임은 코드**. 뛰기·떨기·흔들기·숨쉬기·눌림 같은 움직임은 그림 한 장을 코드로 움직여 만든다. 그래서 프레임마다 그릴 필요가 없다.

## 1. 공통 규격 (모든 그림)
- PNG, **배경 완전 투명**(흰 배경이면 콩깍지의 '배경 지우기'로 지워도 된다)
- 정사각 캔버스 **1024×1024**, 캐릭터는 가운데, **발바닥(바닥선)이 아래에서 12% 높이에 오도록**. 모든 표정·모든 캐릭터가 같은 바닥선·같은 크기여야 움직일 때 튀지 않는다.
- 정면 기준. 걷기 그림만 옆모습(눈이 **왼쪽**을 보게, 반대쪽은 코드로 뒤집음).
- 그림자·바닥 선·글씨는 넣지 않는다(효과는 따로 받음).
- 파일 위치·이름: `Assets/Characters/<캐릭터>/<표정>.png` (예: `Assets/Characters/chick/happy.png`)

## 3. 캐릭터마다 필요한 표정 그림 (14장, ★ 9장은 필수)
| 파일 | 모습 | 쓰이는 곳 |
|---|---|---|
| ★ `idle.png` | 기본(무표정) | 대기·숨쉬기·빼꼼·대부분의 움직임 |
| ★ `blink.png` | 눈 감음(같은 자세) | 눈 깜빡임, 쓰다듬기 |
| ★ `sleep.png` | 졸며 눈 감고 고개 살짝 숙임 | 오래 가만히 있을 때, 싱잉볼 호흡 |
| ★ `happy.png` | 입 벌려 웃음 | 작업 끝남, 쓰다듬기 |
| ★ `surprised.png` | 눈 동그랗게, 입 '오' | 파일이 다가옴, 떨어뜨림, 놀람 |
| ★ `sad.png` | 시무룩(눈 처짐) | 작업 실패 |
| ★ `handup.png` | 한쪽 손(날개·지느러미) 번쩍 | 승인 기다림, 귀환 브리핑 손 흔들기 |
| ★ `mouthopen.png` | 입을 크게 벌림(받아먹기) | 드롭 변환: 파일 받기·결과 뱉기 |
| ★ `squish.png` | 위에서 눌려 납작·눈 질끈 | 쓰다듬기, 착지 |
| `dangle.png` | 들려서 대롱대롱(몸 길쭉) | 끌고 다닐 때 |
| `walk1.png`, `walk2.png` | 옆모습 걷기 두 동작 | 돌아다니기 |
| `bowl.png` | 싱잉볼을 안고 앉음 | 싱잉볼 쉼 |
| `grumpy.png` | 시큰둥·째려봄 | 너무 자주 찌를 때, 그만두기 |

- ☆ 없는 4종(`dangle`, `walk1·2`, `bowl`, `grumpy`)이 없으면 `idle`이나 비슷한 표정으로 대신한다.
- 9마리 × 필수 9장 = 81장, 전부면 126장.

## 6. 추천 인터랙션 (새로 생기는 것)
1. **들어서 대롱대롱 + 던지기** — 끄는 동안 매달린 모습, 빠르게 놓으면 미끄러지다 멈춤(화면 밖으로는 안 나감).
2. **오래 두면 졸기** — 5분 동안 펫과 상호작용이 없으면 zz. 클릭하면 깸.
3. **너무 자주 찌르면 삐침** — 귀여운 반응, 3초 뒤 풀림.
4. **돌아다니기(설정, 기본 꺼짐)** — 가끔 화면 아래를 조금 걷는다. 빼꼼·서랍이 열려 있으면 안 움직임.
5. **펫끼리 반응** — 두 펫이 가까우면 서로 바라보고 하트.
6. **작업 상태 반응** — 끝남·기다림·실패마다 다른 표정과 효과(지금은 콩알만 바뀜).
