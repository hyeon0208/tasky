# F7 편지
- 작성: 2026-10-22 · 요청자: 사용자 · 상태: 보류
- (추정) 표시는 기획안 v0.1·v0.3에서 가져온 내용으로, 사용자가 아직 확인하지 않은 부분

## 문제
서로 다른 곳에서 Mac으로 일하는 커플·친구가 "생각났어", "수고했어" 같은 짧은 마음을 가볍게 전할 방법이 없다. 메신저는 대화를 시작해야 해서 부담스럽다. (추정)

## 원하는 결과
- 한 사람과 연결해 짧은 글과 손그림 편지를 주고받는다. (추정)
- 받은 편지는 봉투로만 보이고, 내가 열 때 내용이 보인다. (추정)
- 하트·토닥·웃음 반응 하나로 답할 수 있다. 답을 재촉하지 않는다. (추정)

## 범위
- 포함: 1:1 연결(1회용 초대 코드, 양쪽 동의), 글 200자 + 손그림(펜·지우개·되돌리기·전체 지우기), 봉투·편지함, 반응 3종, 오프라인일 때 보내기 대기 후 재전송(같은 편지 중복 없음), 연결 해제, 내 편지함에서 지우기, F8 브리핑 맨 앞에 도착한 편지 (추정)
- 제외: 여러 명·그룹, 읽음 표시, 종단간 암호화(비밀 편지로 홍보하지 않음), 파일 첨부, 함께 울림(F10) (추정)

## 제약
- 서버는 Supabase(확정). 편지와 연결 정보만 서버로 간다. 에이전트 데이터는 이 Mac 밖으로 나가지 않는다.
- 앱에는 공개 키(anon)만 넣고 관리자 키는 넣지 않는다. 다른 사람의 편지는 서버 권한 규칙으로 막는다.
- 편지는 알림 등급을 따른다: 쉬는 중에는 보류, 빼꼼일 때는 봉투 점. (추정)

## 성공 기준
- [ ] 두 Mac에서 초대 코드로 연결된다
- [ ] 글·그림 편지를 보내면 상대 펫에 봉투가 생기고, 열면 내용이 보인다
- [ ] 반응을 보내면 상대에게 표시된다
- [ ] 오프라인에서 보낸 편지는 연결되면 한 번만 도착한다
- [ ] 연결을 끊으면 새 편지를 보낼 수 없다
- [ ] 다른 계정은 남의 편지·그림을 읽을 수 없다

## 열린 질문
1. 로그인 방식: 이메일 매직 링크 / Apple로 로그인 / 익명 계정(기기에 저장)
2. 편지 쓰기 창의 위치와 크기
3. 편지 도착 알림: 펫 봉투만 / 알림음·메시지 창도
4. 지우기 범위: 내 편지함에서만 / 양쪽 모두
5. Supabase 프로젝트 준비(사용자가 만들고 URL·공개 키 전달)
