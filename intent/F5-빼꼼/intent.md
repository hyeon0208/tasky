# F5 빼꼼
- 작성: 2026-10-22 (소급 작성) · 요청자: 사용자 · 상태: 구현됨
- 성공 기준 표시: ✅ 확인함 · ❓ 화면에서 미확인

## 문제
펫이 항상 화면에 있으면 작업 화면을 가린다.

## 원하는 결과
- 사용자가 펫을 화면 가장자리·구석에 둘 때만 몸을 숨기고 눈만 내민다(빼꼼).
- 빼꼼 상태에서도 메시지·기능을 그대로 쓴다.

## 범위
- 포함: 좌·우·아래 가장자리, 아래 두 구석. 호버 시 고개 더 내밀기. 구석에서는 부채꼴 링.
- 제외: 위쪽 가장자리(메뉴 막대), 끌고 오는 파일을 미리 감지해 고개 내밀기(미구현), 화면 공유 시 숨김(미구현)

## 제약
- 가장자리 24pt 안에 놓을 때만 빼꼼. 기본은 빼꼼이 아니다.

## 성공 기준
- ✅ 자체 검사: 가장자리 판정, 숨김 비율, 링 칸이 화면 안·겹치지 않음
- ❓ 실제 화면에서 빼꼼 모양과 호버 동작
