## 지금 상태 (코드로 확인)
- 클릭: `PetView.mouseUp` → `petClicked()`(PetController.swift:673)가 **원형 메뉴를 연다**. 호버는 붙은 알약만 펼친다(`petHover`, :280). 두 번 누르기 처리는 없다.
- 붙기: `Dock`(Geometry.swift:4)에 `.top`이 이미 있다(위 가장자리 가운데). 알약 내용은 `islandContent`(:176), 크기는 `Geometry.islandFrame`(:67).

- 원형 메뉴: `RingView`의 `GlassButton`(RingView.swift:332) — macOS 26 `NSGlassEffectView`, 아니면 흐림 + 빛 테두리·반사광.
- 메뉴 막대: `App.setUpStatusItem`, 아이콘 `MenuBarIcon`(템플릿), 우클릭 = 잠 안 자기(:1757), 켜지면 `AwakeIcon`(컵·김).
- 작업 이름: `AgentSession.name` = 폴더 이름 · 도구(Agents.swift:140). 훅 입력에는 `transcript_path`가 오지만 저장하지 않는다.
- 끝남 알림: `Stop`마다 알림(Agents.swift:195), 보고 있는지 확인 없음(PetController.swift:401). `tasky_app`(터미널 번들 ID)은 이미 받는다(:33).
- 단축키: `HotKey`(Carbon, 권한 불필요). 클립보드 id 1, 창 정리·캡처 여러 id.

## 우려 사항
1. **누르기 동작이 바뀐다.** 지금은 한 번 누르면 원형 메뉴다. 개편 후: 올리기 = 원형 메뉴, 한 번 = 오늘 카드, 두 번 = 빠른 실행.
   - 올리기로 열면 지나가다 실수로 열릴 수 있다 → 0.35초 머물렀을 때만 열고, 끌기·던지기 중에는 열지 않는다(사용자 결정 2026-11-04).
   - 한 번과 두 번을 가리려면 한 번 누르기를 시스템 두 번 누르기 간격(`NSEvent.doubleClickInterval`, 보통 0.25~0.5초)만큼 기다렸다 처리해야 한다. 카드가 그만큼 늦게 열린다.
   - 쓰다듬기·찌르기(F11)는 그대로 클릭 횟수로 판정한다.
2. **위 가운데 알약(A).** `.top` 붙기를 쓰고, 처음 위치를 화면 위 가운데로 바꾼다(추정: 이미 다른 곳에 둔 사용자는 그 자리 유지). 알약 내용을 칩(할 일 수·다음 일정·상태 점)으로 바꾸고, 라이트·다크는 `NSApp.effectiveAppearance`에 따라 색을 고른다. 펼침(호버) 패널은 오늘 카드와 같은 내용.
3. **머리 위 칩(B).** 큰 구슬(F14) 대신 펫 위 자식 패널에 칩. `BeadsSetting`과 구슬 코드는 끄고 남긴다(싱잉볼처럼). 마우스 통과.
4. **메뉴 막대만(C).** 설정 '보이는 방식': 곰과 알약 / 메뉴 막대만. 메뉴 막대만이면 펫 창을 숨기고(`setVisible(false)` 재사용) 상태 칸 제목에 `3 · 2:00 치과` + 상태 점. 왼쪽 클릭 = 오늘 카드(메뉴 막대 아래), 우클릭 = 잠 안 자기(그대로), 컵 아이콘 그대로. 알림은 메뉴 막대 아래 말풍선.
5. **유리 패널.** 오늘 카드·알약 펼침·빠른 실행은 `makeGlass`(RingView.swift:315)를 함께 쓰도록 꺼낸다. 원형 메뉴는 7칸(할 일·빠른 실행·작업 목록·그 사이 소식·잠 안 자기·빼꼼·설정), 칸 이름표 상시, 색 있는 SF Symbols, 칸을 잇는 유리 고리. 캡처·클립보드·창 정리·서랍 칸은 뺀다(서랍은 ⌥ 올리기 그대로). 사용자가 저장한 칸 순서(F21)는 새 목록에 맞춰 `RingOrder.apply`가 정리한다.
6. **빠른 실행(G).** 입력 한 줄 → 후보 목록(↩ 첫 번째, ⌘↩ 두 번째).
   - 날짜·시간이 읽히면 일정/할 일 추가(F24 `QuickParse` 재사용)
   - 기능 이름과 맞으면 실행: 캡처(영역·창·전체), 창 정리 동작 이름(왼쪽 반 등), 클립보드, 할 일 창, 설정
   - 그 밖에는 할 일·클립보드 기록 검색
   - 기본 단축키 ⌘⇧P(설정에서 변경), 시스템·다른 앱과 겹치면 설정에 표시(F15 방식). 열 때만 키 창(F24 할 일 창과 같은 예외).
7. **세션 이름.** 훅 클라이언트가 `transcript_path`를 payload에 그대로 넘기고, 서버가 세션마다 그 파일 끝 64KB에서 마지막 `custom-title`, 없으면 `ai-title`을 읽는다(파일 읽기만, 수정 없음). 끝남·내 차례 때만 읽고 캐시. 없으면 폴더 이름. 문구: "플레이리스트 개발 작업이 내 답을 기다려요".
8. **끝남 알림 줄이기.** `UserPromptSubmit` 시각을 세션에 저장 → `Stop`에서 걸린 시간 < 기준(기본 10초)이면 조용히, 또는 앞 앱 번들 ID == `tasky_app`이면 조용히(상태 점만). 기준은 설정 '작업 알림'에 초 입력과 설명. 순수 함수로 빼서 자체 검사. '내 차례'·'실패'는 그대로.
9. **할 일 창·설정·알림(H·I·J).** H: 큰 제목·진행 막대·탭·아래 입력(지금 `TaskWindow` 다시 그림). I: 설정 첫 화면을 기능 카드 9장으로, 카드를 누르면 지금 탭 내용이 아래로 펼쳐짐(탭 내용 코드는 그대로 재사용). J: 알림 문구를 짧고 다정하게(문구 표), 할 일 완료 토스트(되돌리기).
10. **양이 크다.** 단계를 나눠 단계마다 빌드·검사·사용자 화면 확인을 받는다(plan에서 정함). 순서 제안: 알림 고치기(7·8) → 누르기·원형 메뉴(1·5) → 오늘 카드·알약·칩(2·3) → 빠른 실행(6) → 메뉴 막대만(4) → H·I·J(9).
