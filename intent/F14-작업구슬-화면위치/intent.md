# F14 작업 구슬·화면 위치로 알려 주기
- 작성: 2026-10-28 · 요청자: 사용자 · 상태: 승인됨(2026-10-28)
- (추정) 표시는 사용자가 아직 확인하지 않은 부분
- 근거 시안(사용자 확정 2026-10-28): 같은 캔버스의 '작업 구슬 2안: 읽히는 구슬'

## 문제
- 펫만 봐서는 Claude Code·Codex·변환이 몇 개 돌고 있는지, 무엇이 내 차례인지 알 수 없다.
- 앞에서 보는 작업과 뒤에서 도는 작업이 구분되지 않는다.

## 원하는 결과
- 펫 머리 위 구슬: 작업 하나당 구슬 하나. 입체(반사광·그림자).
  - 상태는 그림으로: 도는 고리 = 일하는 중, ! = 내 차례(승인 대기), ✓ = 끝남(아직 안 봄), 빨강 × = 실패. 색도 함께(파랑·주황·초록·빨강).
  - 종류는 꼬리표: C = Claude Code, X = Codex, ⇄ = 변환.
  - 앞 작업은 큰 구슬 하나(가운데), 뒤 작업은 옆에 작게. 4개를 넘으면 뒤 작업은 "+N" 하나로 묶는다.
  - 커서를 올리면 폴더 이름·걸린 시간, 누르면 작업 목록.
- 앞/뒤 기준: 지금 맨 앞에 있는 터미널 앱에서 도는 세션이 앞, 나머지 세션과 변환은 뒤(사용자 확인).
- 화면 위치로 알려 주기:
  - 펫 눈이 내 차례인 작업 쪽(그 작업 창·다른 모니터 방향)을 본다.
  - 다른 모니터에서 승인을 기다리면 펫이 그 모니터 쪽 가장자리로 빼꼼한다. (추정: 자동 이동은 설정으로 끌 수 있게)
  - 다 끝나면 눈을 감고 쉰다.

## 범위
- 포함: 구슬 표시, 앞/뒤 구분, 눈 방향, 다른 모니터 쪽 빼꼼
- 제외: 일의 양에 따라 펫 높이 바꾸기, 창이 가리면 비켜 앉기(다음 단계 후보)

## 제약
- 작업 상태는 기존 훅(F4)으로 받은 것만 쓴다. 터미널 내용은 읽지 않는다.
- 맨 앞 앱 확인은 NSWorkspace의 앞 앱 정보만 쓴다(권한 없음). 세션과 터미널 창을 잇는 방법은 spec에서 정한다.

## 성공 기준
- [ ] 세션 2개·변환 1개가 돌면 구슬 3개가 보이고, 승인 대기 세션은 !로 바뀐다
- [ ] 앞 터미널의 세션이 큰 구슬로 보인다
- [ ] 승인 대기가 생기면 펫 눈이 그쪽을 본다
- [ ] 동작 줄이기면 고리가 돌지 않고 그림만 바뀐다
