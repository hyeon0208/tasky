## 작업 순서와 검사
### 1. `BeadModel` (순수)
- 입력: 세션 목록, 진행 중 변환 수, 맨 앞 앱 번들 ID, 받는 도구 판정.
- 규칙: 일하는 중·대기·실패 + 안 본 끝남 / 받지 않는 도구 제외 / 앞 = `app == 맨 앞 앱`, 그중 가장 최근 하나가 큰 구슬(가운데) / 나머지는 대기→실패→끝→일하는 중 순으로 양옆 / 4개 넘으면 3개 + "+N".
- 출력: `[Bead(kind: state/convert/more(n), tool, big, title)]`.
- **검사:** spec 검증 방법의 네 경우.

### 2. `BeadsPanel`
- 펫 위 자식 패널(`follow`). 위치는 몸 위 가운데, 시계가 보이면 시계 위.
- 구슬 층: 방사형 그라데이션 + 반사광 + 그림자 + 그림(SF Symbol 또는 글자) + 꼬리표, 일하는 중은 고리 회전(`CABasicAnimation` 1.2초, 동작 줄이기면 없음).
- 마우스: 구슬 위에서만 받는다(`hitTest`). 올리면 이름표, 누르면 작업 목록.
- **검사:** 빌드.

### 3. 연결
- 갱신 시점: `agentsChanged`, `didActivateApplicationNotification`, `convert` 시작/끝, `place`, 설정 바뀜. 펫이 숨으면 패널도 숨김.
- 기울기: 대기 구슬이 있으면 그 구슬의 x가 몸 가운데보다 왼쪽이면 -, 오른쪽이면 +; 큰 구슬이면 0(정면 위를 봄). 없으면 0.
- 안 본 끝남만 남으면 `react(.sleepy)` 대신 눈감음 그림(있으면) — 없는 그림은 대신 규칙대로.
- **검사:** 빌드, 자체 검사 전체.

### 4. 마무리
- 독립 검토 → 반영 → 다른 점 기록, 커밋·push.

## 확인하지 못할 것 (사용자 확인)
- 구슬 모습·고리 회전·기울기 느낌, 맨 앞 앱이 바뀔 때 큰 구슬이 바뀌는지.

## 구현 결과와 plan과 다른 점 (2026-10-29)
- 자체 검사 통과(본 끝남 제외, 앞 앱의 가장 최근만 큰 구슬, 6개 → 3개 + "+3", 받지 않는 도구 제외·변환 남음).
- 독립 검토 반영: 기울기 방향을 몸 가운데 기준으로(화면 가장자리), 시계가 숨으면 구슬이 내려옴, 첫 클릭이 먹히게, 이름표의 'N분 전'은 올릴 때 계산(마지막 활동 기준), 이름 바꾸기 때 설정을 키마다 옮김.
- 다른 점: '안 본 끝남만 남으면 눈 감은 표정'은 하지 않음(병아리에 눈감음 그림이 없음, 그림이 생기면 추가). 패널 이름은 `BeadsView`(+ FloatingPanel).
- 남은 것(검토 지적, 화면 확인 후 결정): 시계를 '커서 올렸을 때'로 두면 구슬이 오르내림, 화면 맨 위에서 구슬과 시계 겹침, 흔들기 동작 중에는 기울기가 잠깐 풀림.
- 확인 못 함: 구슬 모습·고리 회전·기울기, 앞 앱 전환.
