# F1 원형 메뉴(콩 링)와 펫 기본 동작
- 작성: 2026-10-22 (소급 작성) · 요청자: 사용자 · 상태: 구현됨
- 성공 기준 표시: ✅ 확인함 · ❓ 화면에서 미확인

## 문제
펫을 클릭했을 때 다양한 기능에 빠르게 닿을 방법이 없다. 펫은 항상 바탕화면에 있어야 한다.

## 원하는 결과
- 펫을 클릭하면 원형으로 기능들이 펼쳐진다(예: 싱잉볼 명상).
- 펫은 처음에 화면 정중앙에 있고, 원하는 위치로 옮길 수 있다.
- 펫을 여러 마리 둘 수 있다(별도 문서: 여러-펫).

## 범위
- 포함: 8칸 원형 메뉴, 12시 상황 칸, 숫자 1~8·Esc, 드래그 이동, 문질러 쓰다듬기, 위치·모니터 기억, 메뉴 막대 아이콘(숨기기·종료)
- 제외: 3D 캐릭터·효과음(추후 개선), 원형 메뉴 전역 단축키(미구현)

## 제약
- 포커스를 뺏지 않고, 펫 뒤 앱의 클릭을 막지 않는다. Swift 네이티브, macOS 14+.

## 성공 기준
- ✅ 빌드·자체 검사 통과, 처음 위치가 화면 중앙(창 위치로 확인)
- ❓ 클릭 시 링 표시, 칸 실행, 닫힌 뒤 포커스 복귀

## 열린 질문
- 원형 메뉴를 여는 전역 단축키를 둘지
