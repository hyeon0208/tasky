# F12 키보드 편의 (한영 전환 키 · 키 반복 속도)
- 작성: 2026-10-27 · 요청자: 사용자 · 상태: 승인됨(2026-10-27)
- 참고: /Applications/gksdud.app 2.0.1 (메뉴 막대 앱, 한영 전환을 빠르게)
- (추정) 표시는 사용자가 아직 확인하지 않은 부분

## 문제
- macOS 기본 한영 전환(Caps Lock·⌃Space)은 반응이 늦거나 Caps Lock을 짧게 눌렀을 때 전환이 씹히는 경우가 있다. 오른쪽 ⌘·⌥ 같은 키로 바로 바꾸고 싶다. (추정)
- 스페이스·지우기 등 키를 누르고 있을 때 반복 속도를 시스템 설정 최대치보다 더 빠르게 하고 싶다. 지금은 터미널 명령으로만 가능하다.

## 원하는 결과
- 한영 전환은 기본 꺼짐(사용자 결정, gksdud와 겹치지 않게). 켜면 설정에서 한영 전환에 쓸 키를 Caps Lock·오른쪽 ⌘·오른쪽 ⌥ 중에서 고르면 그 키로 즉시 전환된다. 기본값은 Caps Lock(사용자 결정).
- 설정에서 '반복 시작까지 시간'과 '반복 속도'를 슬라이더로 바꾼다. 시스템 설정보다 빠른 값도 고를 수 있고, 각 값이 무엇을 뜻하는지(밀리초) 보여 준다.

## 참고 앱 관찰 (gksdud, 실행 파일 문자열로 확인)
- 고를 수 있는 키: caps-lock, right-command, right-option
- 키 입력을 직접 읽는 하드웨어 입력 장치 접근(IOHID)과 손쉬운 사용 권한을 쓰는 것으로 보인다.
- Caps Lock을 길게 누르면 원래 대문자 고정, 짧게 누르면 한영 전환을 구분하는 기능이 있다.

## 키 반복 설정 설명 (사용자가 준 명령)
- `defaults write -g InitialKeyRepeat -int 10` — 키를 누른 뒤 반복이 시작되기까지의 시간. 단위는 15ms, 10이면 약 150ms. 시스템 설정의 가장 짧은 값은 15(약 225ms).
- `defaults write -g KeyRepeat -int 1` — 반복이 시작된 뒤 글자가 찍히는 간격. 단위는 15ms, 1이면 약 15ms(초당 약 66번). 시스템 설정의 가장 빠른 값은 2(약 30ms).
- 값은 사용자 계정의 전역 설정에 저장되고, **로그아웃 후 다시 로그인해야** 모든 앱에 적용된다(이미 켜진 앱은 바뀌지 않음). 되돌리려면 `defaults delete -g InitialKeyRepeat` / `KeyRepeat` 또는 시스템 설정에서 다시 조절.

## 범위
- 포함: 한영 전환 키 설정, Caps Lock 길게 누르기 대문자 고정, 키 반복 두 값 슬라이더와 설명, 기본값으로 되돌리기
- 제외: 다른 키 재배치 전반, 단축키 매크로, 한·영 외 입력 소스 순환

## 제약
- 이 기능에 한해 입력 모니터링 권한을 받는다(사용자 결정, spec에서 손쉬운 사용 권한은 필요 없어 뺌). 권한은 이 기능을 켤 때만 요청하고, 끄면 키 입력을 읽지 않는다. 읽은 키는 전환 키 판단에만 쓰고 저장·전송하지 않는다.
- 권한을 주지 않으면 이 기능만 꺼지고 나머지 기능은 그대로다.
- 시스템 설정 값을 바꾸는 기능이므로 바꾸기 전에 원래 값을 기억하고, 되돌리기를 항상 제공한다.

## 성공 기준
- [ ] 설정 '키보드'에서 한영 전환을 켜고 키(Caps Lock·오른쪽 ⌘·오른쪽 ⌥, 기본 Caps Lock)를 고르면, 그 키를 한 번 누를 때 입력 소스가 한↔영으로 바뀐다
- [ ] Caps Lock을 고른 경우 약 0.5초 이상 누르면 대문자 고정이 켜지고 꺼진다
- [ ] 전환을 끄면 키 입력을 읽지 않고, 권한을 주지 않으면 이 기능만 꺼진 채 안내가 보인다
- [ ] 키 반복 슬라이더 두 개(반복 시작 10~120, 반복 속도 1~120 단위)가 밀리초를 보여 주고, 바꾸면 전역 설정에 저장되며 로그아웃 후 적용된다는 안내가 보인다
- [ ] '기본값으로 되돌리기'가 바꾸기 전 값으로(없었다면 시스템 기본으로) 돌려놓는다

## 열린 질문
1. ✅ 전환 키 후보와 기본값 — Caps Lock·오른쪽 ⌘·오른쪽 ⌥, 기본 Caps Lock
2. ✅ Caps Lock 길게 누르기 — 짧게 누르면 한영 전환, 약 0.5초 이상 누르면 대문자 고정(Caps Lock을 전환 키로 고른 경우만)
3. ✅ 가장 빠른 값 — 반복 시작 10(약 150ms), 반복 속도 1(약 15ms)까지. 슬라이더 옆에 밀리초 표시, 기본값으로 되돌리기
4. ✅ 콩깍지 설정 창에 '키보드' 구역으로(모든 펫 공통 값)
