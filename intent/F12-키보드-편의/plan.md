## 작업 순서와 각 단계의 검사

### 1. 판정 `SwitchJudge` (순수)
- 입력: (키 코드, 눌림/뗌/수정키 변화, 시각), 고른 전환 키. 출력: `.toggleInput` / `.toggleCapsLock` / `nil`.
- 오른쪽 ⌘(키 코드 54)·오른쪽 ⌥(61): `flagsChanged`로 눌림 → 다른 키가 끼지 않고 뗌 → 전환. 왼쪽(55·58)은 무시.
- Caps Lock(→ F18, 키 코드 79): 첫 눌림 시각 기억(자동 반복 눌림은 무시) → 뗄 때 0.5초 미만이면 전환, 이상이면 대문자 고정. 0.5초가 지나면 떼기 전에 바로 대문자 고정(누르고 있는 동안 알 수 있게) 후 뗄 때는 아무것도 안 함.
- **검사:** 혼자 누름 → 전환, ⌘ 누른 채 C → 전환 없음, 왼쪽 ⌘ → 없음, Caps 0.49초 → 전환, 0.5초 → 대문자 고정(한 번만), 자동 반복 눌림 무시.

### 2. Caps Lock 바꿈 `KeyMapping`
- `hidutil property --get UserKeyMapping`으로 지금 매핑을 읽고, Caps(0x700000039) → F18(0x70000006D) 항목만 더하거나 뺀 목록을 `--set`. 다른 항목은 그대로.
- 합치기·빼기는 순수 함수(배열 → 배열), 실행은 `Process`.
- **검사:** 빈 목록에 더하기, 다른 항목이 있을 때 더하고 빼면 다른 항목 보존, 두 번 더해도 하나.

### 3. 감지·전환 `KeySwitcher`
- 켤 때: `CGPreflightListenEventAccess`가 아니면 `CGRequestListenEventAccess`(시스템 권한 창) 후 중단하고 설정에 "권한 필요" 표시. 권한이 있으면 Caps를 고른 경우 매핑을 걸고, 듣기 전용 이벤트 탭(keyDown·keyUp·flagsChanged) 시작.
- 판정 결과 실행: 입력 전환은 `TISCreateInputSourceList`에서 켜진 한국어(언어 `ko`) 하나와 영문(ASCII 가능 키보드 레이아웃) 하나를 찾아 `TISSelectInputSource`. 대문자 고정은 `IOHIDGetModifierLockState`/`IOHIDSetModifierLockState`로 뒤집기.
- 끌 때: 탭 해제, 매핑 빼기. 전환 키를 바꾸면 끄고 다시 켠다.
- 탭이 시스템에 의해 꺼지면(`tapDisabledByTimeout`) 다시 켠다.
- **검사:** 빌드. 입력 소스 찾기 규칙은 순수 함수로 분리해 검사(ko·ABC 있음 → 둘 다, 한국어 없음 → nil).

### 4. 키 반복 `KeyRepeat`
- 전역 도메인 값 읽기·쓰기(`CFPreferencesCopyAppValue`/`SetAppValue` + `kCFPreferencesAnyApplication`, 저장 후 synchronize).
- 처음 쓰기 전에 원래 값(없으면 '없음')을 우리 설정에 한 번만 기록. 되돌리기는 그 값으로, '없음'이면 키 삭제.
- ms 변환: 값 × 15.
- **검사:** ms 변환, 원래 값은 처음 한 번만 기록, '없음' 되돌리기 → 삭제 지시. 실제 전역 값은 자체 검사에서 건드리지 않는다.

### 5. 설정 '키보드' 구역 (`PetController`, 모든 펫 공통)
- 한영 전환 켜기(기본 꺼짐), 전환 키 고르기(Caps Lock·오른쪽 ⌘·오른쪽 ⌥), 권한이 없으면 "입력 모니터링 권한이 필요해요" + '권한 열기'(시스템 설정의 입력 모니터링 화면).
- Caps Lock을 고르면 한 줄 안내: "길게 누르면 대문자 고정. 콩깍지가 비정상 종료되면 다시 켜거나 Mac을 재시작하면 돌아와요".
- 반복 시작(10~120)·반복 속도(1~120) 슬라이더, 옆에 "약 150ms" 표시, "로그아웃 후 모든 앱에 적용돼요", '되돌리기'.
- `App`: 실행 때 켜져 있으면 시작, `willTerminate` 때 매핑 빼기.
- **검사:** 빌드, 자체 검사 전체 통과.

### 6. 마무리
- 새 문맥 서브에이전트로 독립 검토 → 반영 → plan과 다른 점 기록.
- 이 Mac의 실제 매핑·반복 값은 사용자가 켜기 전까지 바꾸지 않는다. 실행 중인 펫은 사용자가 요청할 때만 다시 띄운다.

## 구현 결과와 plan과 다른 점 (2026-10-27)
- 자체 검사 통과(판정 15개 경우, 매핑 합치기·빼기·읽기 실패 시 안 바꿈, 입력 소스 찾기, ms·되돌리기). 자체 검사는 실제 키 매핑·반복 값을 바꾸지 않음(전후 확인).
- 독립 검토 반영:
  - 사용자가 직접 만든 Caps→F18 매핑은 지우지 않음(우리가 더한 때만 기록해 뺌), hidutil 출력을 다 읽지 못하면 아무것도 바꾸지 않음.
  - 터미널 Ctrl-C·kill에도 Caps Lock 되돌림, 권한을 거두면 감지·바꿈 중단, 한국어·영문 소스가 없으면 Caps Lock을 건드리지 않음.
  - 떼기를 놓친 뒤 다음 누름이 꼬이지 않음, 반복 눌림 없이도 0.5초에 대문자 고정, ⌘-클릭·왼쪽 ⌘을 누른 채·1초 넘게 누름은 전환 안 함, 한국어 자판이 둘이어도 언어 기준으로 전환.
- 다른 점: 오른쪽 ⌘·⌥를 1초 넘게 누르고 떼면 전환하지 않는다(검토 제안, 다른 단축키 실수 방지). 권한을 준 뒤에는 설정 창을 다시 열 때 감지가 시작된다.
- 확인 못 함: 실제 전환(한국어 입력기에서 시스템 전환 함수가 가끔 화면만 바뀌는 알려진 문제 포함), 대문자 고정 불빛, 권한 창, 로그아웃 후 반복 속도.
