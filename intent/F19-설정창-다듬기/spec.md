## 지금 상태
- `SettingsTabs`: 위쪽 아이콘 탭 줄(폭 520) + 아래 내용, 탭을 바꾸면 창 높이가 내용에 맞게 바뀜. 탭 9개(개발자 포함).
- 내용은 `SettingsTabs.grid`(이름 칸 오른쪽 정렬 + 값 칸) 격자.

- 왼쪽 목록: 아이콘(색 있는 둥근 사각 배경, 시스템 설정과 같은 모양) + 이름, 행 높이 28, 고른 행은 강조색 배경. ↑↓로 이동.
- 오른쪽: 맨 위 탭 제목(17pt 굵게), 아래 구역 제목(11pt 회색) + 둥근 카드 안에 줄들. 줄은 왼쪽 이름·오른쪽 컨트롤, 설명은 이름 아래 11pt 회색 한 줄.
- 스위치는 체크 상자 대신 `NSSwitch`.
- 개발자·정보는 목록 아래쪽에 구분선 뒤로.

## 설계
- `SettingsTabs`를 `SettingsWindow` 구조로 바꾼다: 왼쪽 `NSTableView`(원본 목록) + 오른쪽 `NSScrollView`. `SettingsTab` 모양(id·title·symbol·content)은 그대로 → 각 탭 내용 코드는 문구만 바뀐다.
- `grid` 대신 `section(title, rows)` + `row(name, detail, control)` 도우미 두 개(카드 배경). 탭 내용 함수들은 이걸로 옮긴다.
- 마지막 탭 기억(`settingsTab`)·펫 따라가기·바깥 클릭 닫기는 그대로.
- 디자인 다듬기는 구현 뒤 디자인 스킬(emil-design-eng)로 간격·정렬·움직임을 검토해 한 번 더 고친다.

## 우려
- 창이 커진다(520 → 680 폭): 작은 화면에서는 펫 옆 대신 화면 가운데에 둔다(넘칠 때만).
- 높이를 고정하면 짧은 탭(정보)은 아래가 비어 보인다 — 시스템 설정과 같은 방식이라 받아들인다.
