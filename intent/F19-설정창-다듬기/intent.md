## 문제
- 탭이 9개로 늘어 위쪽 탭 줄이 창 폭을 넘쳐 잘렸다(임시로 폭을 나눠 넣었지만 빠듯함).
- 옵션 이름·설명이 개발자 말투라 무엇을 하는지 바로 알기 어렵다(예: '깍지', '빼꼼', '열기 키').

## 원하는 결과
- 탭이 늘어도 잘리지 않는 구조: macOS 시스템 설정처럼 왼쪽 세로 목록 + 오른쪽 내용(사용자 결정)
- 모든 옵션 이름은 "무엇이 되는지"로, 설명은 한 줄로. 처음 보는 사람이 설명 없이 이해한다.
- 디자인 전용 스킬로 간격·글자 크기·정렬을 다듬는다.

## 범위
- 포함: 설정 창 구조, 모든 탭의 문구·설명, 간격·정렬
- 제외: 원형 메뉴, 각 기능 동작 변경
