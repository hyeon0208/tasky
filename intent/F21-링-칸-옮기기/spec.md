# F21 링 칸 옮기기 — spec
- 작성: 2026-10-30 · 근거: intent.md(승인됨), 시안 C '자석 젤리' · 상태: 초안(승인 대기)

## 지금 상태 (코드로 확인)
- 메인 링 칸은 `PetController.mainSlots`가 고정 순서로 만든다. 첫 칸은 '상황 칸'(그 사이 N건 > 기다리는 작업 > 끝난 작업 > 변환 결과 > 쓰다듬기, 내용이 바뀜).
- `RingView`는 칸마다 `GlassButton`, 칸 위치는 `centers`(자유 상태 반원·가장자리 반원·알약 부채꼴). `mouseDown`에서 바로 실행, 숫자 키 1~N 실행.
- 파일을 끌어 올 때 여는 드롭 변환 링도 같은 `RingView`.

## 우려 사항
1. **칸 구별 — 추천: `Slot`에 `id`를 둔다.** 상황 칸은 내용이 바뀌어도 id `status` 하나. 나머지 drawer·bowl·clipboard·agents·peek·settings.
2. **저장 — 추천: UserDefaults `ringOrder`(id 배열), 앱 전체 하나.** 저장에 없는 새 칸은 기본 순서 자리에 끼워 넣고, 없어진 칸은 무시(순수 함수 `RingOrder.apply`, 자체 검사).
3. **클릭과 들기 구별 — 추천:**
   - 누름 → 0.3초 동안 3pt 넘게 안 움직이면 '들기'. 그 전에 떼면 실행(지금 `mouseDown` 실행을 `mouseUp`으로 옮김). 0.3초 전에 3pt 넘게 움직이면 아무것도 안 함(실수 방지).
   - 들기 시작에 칸이 살짝 커지는 반응(눌렀다는 확인).
   - 숫자 키·VoiceOver 순서도 새 순서를 따른다.
4. **움직임(시안 C 자석 젤리) — 추천: 칸 뷰의 layer transform을 스프링으로 한 프레임씩(60fps `Ticker` '링 칸 옮기기', 들고 있거나 칸이 아직 움직이는 동안만).**
   - 든 칸: 커서를 빠른 스프링으로 따라감, 1.15배, 움직이는 방향으로 늘어남(속도에 비례, 최대 45%)·수직으로 줄어듦.
   - 다른 칸 자리에 40pt 안으로 가까워지면 순서를 바꾸고, 밀려난 칸들은 덜 감쇠된 스프링(살짝 출렁)으로 새 자리로.
   - 놓으면 든 칸도 같은 스프링으로 자리에 들어가며 1배로. 이름표는 든 칸을 따라간다.
   - 동작 줄이기면 스프링 없이 바로 자리를 바꾼다.
5. **취소 — 추천: 들고 있는 동안 Esc면 처음 순서로 되돌림.** 링 밖에 놓아도 마지막 순서로 저장(링은 열린 채).
6. **드롭 변환 링은 옮기기 없음.** 파일을 끌고 있는 중이라 들기와 겹친다.
7. **되돌리기 — 추천: 설정 '일반' 탭에 '원형 메뉴 순서 처음대로' 버튼.**

## 요구사항
- R1. 0.3초 꾹 누르면 칸이 들리고, 옆 칸 자리로 가면 순서가 바뀐다.
- R2. 놓으면 저장되고 다음에 열어도 그 순서.
- R3. 짧은 클릭은 지금처럼 실행.
- R4. 동작 줄이기면 움직임 없이 바뀐다.

## 설계
- `RingView.swift`: `Slot.id`, 누름 타이머·들기 상태, 스프링 갱신(`Spring`은 Pet3D.swift 것 재사용), `onReorder: ([String]) -> Void`.
- `RingOrder`(순수): `apply(saved:ids:)`, `move(_:from:to:)` + SelfTest.
- `PetController.mainSlots`: 저장 순서로 정렬, `onReorder`에서 저장.
- 설정: 순서 처음대로 버튼.

## 검증 방법
- 자체 검사: 저장 순서 적용(새 칸 끼우기·없어진 칸 무시), move 앞·뒤 이동.
- 사용자 확인: 꾹 눌러 들기, 젤리 움직임, 저장, 짧은 클릭 실행, 알약 부채꼴에서도 동작.
