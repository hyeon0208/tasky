# 용어

- **기능 무대**: `#features`의 탭 10개 + 영상 하나. 탭을 고르면 제목·설명·영상이 바뀐다.
- **설치 판**: `#download` 안의 회색 판. .dmg/.zip 버튼, 터미널 한 줄 명령, 접히는 .dmg 4단계.
- **새로운 소식**: 설치 판 아래 한 줄. 최신 공개 릴리스의 태그 + 본문 첫 줄.
- **이름 고정 파일**: 릴리스마다 함께 올리는 `Tasky.dmg`·`Tasky.zip`. 사이트 다운로드 버튼이 가리킨다(ADR 0001).
- **공개 릴리스**: draft·prerelease가 아닌 GitHub Release.
