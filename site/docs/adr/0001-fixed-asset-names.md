# 0001. 다운로드는 이름 고정 릴리스 파일로 연결한다

- 상태: 확정 (2026-11-07)

## 맥락
릴리스 파일은 `Tasky-<버전>.dmg`처럼 버전이 붙어 있어 고정 주소가 없다. 시안은 실행 중 GitHub API(인증 없이 IP당 시간당 60회)로 주소를 바꿔 넣었고, 실패하면 릴리스 페이지로 가서 클릭이 한 번 늘었다.

## 결정
앱 `release.sh`가 `Tasky.dmg`·`Tasky.zip`도 함께 올리고, 사이트는 `releases/latest/download/Tasky.dmg`로 바로 연결한다.

## 결과
- 다운로드가 API·빌드·재배포와 무관하게 늘 최신이다.
- 릴리스마다 같은 파일이 두 벌 올라간다. Sparkle appcast는 버전 붙은 zip을 그대로 쓴다.
- 앞으로 파일 이름을 바꾸면 사이트 링크가 깨진다. 이름은 `Tasky.dmg`·`Tasky.zip`으로 유지한다.
- 버리는 안: 빌드 때 주소 주입(새 릴리스마다 재배포 필요), 실행 중 API만 사용(실패 시 클릭 증가).
